# 设置拆分 · 全局设置 / 库设置 · 三方向初稿

状态：**待选**（2026-11-20）

## 问题

现在的 `SettingsView.vue` 是一列 8 个面板：账户、同步、备份与迁移、官方发布、外观、插件与安全、插件目录、关于本机。
其中外观（主题 / 色模式 / 库色）、同步、备份、发布都跟着库走；账户、插件、主题包安装、关于本机跟着这台机器走，
但界面上没有任何东西把这个区别说出来。

## 事实（核对代码后）

- 主题 + 色模式写进库内 `appearance.json`（`theme-host/vaultAppearance.ts`），随库走。
- 主题包（含社区主题 CSS）安装在应用级目录，所有库共用（`extension/globalThemes.ts`）。
- 库色写在本机偏好，按库路径区分（`appearance/vaultColors.ts`）。
- 插件、插件目录、安全模式、编辑器是应用级（`extension/runtime.ts`）。
- 发布草稿 `OfficialPublishDraft` 存在本机：属于库内容的发布，但设置本身不随库。
- 账号、同步服务器是账号级。

## 共同处理

- 同步不再带服务器地址（服务器归「账户」，全局），只留这个库的同步开关、状态、立即同步。
- 安全模式从「插件与安全」里拿出来：它是全局的，和插件放一块会让人以为它跟着库。
- 库色从「外观」里分出来：主题与明暗是全局的，库色是库的。现在两者挤在同一张面板里，用户分不清改的是哪一个。
