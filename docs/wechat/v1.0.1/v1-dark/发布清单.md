# 发布清单 · V5Notes · 深色科技版

## 贴图
- [ ] 图片共 8 张，顺序：cover → point → diagram → point → diagram → point → compare → ending
- [ ] 每张 1080×1440（3:4），PNG；单张 >2MB 时压到 JPG 90
- [ ] 首图 3 秒可懂；标题 ≤20 字：把笔记搬回自己家的服务器
- [ ] 每卡一个信息、一个强调色、标题 ≤2 行；安全区 ≥64px
- [ ] 配文 ≤100 字 + 一个 CTA；结尾卡含二维码/关键词

## 文章
- [ ] 标题：把笔记数据拿回来之后，我又给它加上了实时消息
- [ ] 摘要 ≤54 字（当前 52 字）
- [ ] 封面 1080×460；正文配图 3 张，编号连续
- [ ] 每图有「图N：」图注；段落 ≤4 行
- [ ] HTML 为内联样式，粘贴到微信编辑器不丢样式
- [ ] 手机预览：无乱码、无失效图片
