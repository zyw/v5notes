# 查找替换设计方案

查找界面放进 v5notes 已有的右侧大纲栏。大小写、全词、正则、跳转和替换由 v5md 完成。v5notes 不另做一条边栏，也不把这条边栏搬进编辑器。

## 原则

v5md 是独立的编辑器库。匹配、选区、撤销和「编辑器收到查找快捷键后做什么」留在库里。宿主只决定查找界面画在哪里。

v5notes 的右侧栏是笔记客户端自己的栏，用来放大纲。查找是这栏里的另一个视图。客户端不实现匹配算法，只把查找词和三个开关交给编辑器，再把编辑器返回的序号、总数和错误画出来。

## 现状

- v5md 的查找是插在编辑器顶部的一整行表单，包含查找、替换为、下一个、替换、全部替换和关闭。焦点在编辑器里时，`⌘F` / `Ctrl+F` 由编辑器打开这行表单。
- `@v5md/core` 的 `findMatch` 用 `indexOf` 做区分大小写的字面量查找，到文末后从开头继续。`replaceAllText` 用字符串拆分替换，算一步撤销。
- v5notes 隐藏编辑器内置大纲，在正文右侧自绘一条大纲栏。栏头现在只有「大纲」，下面是按层级缩进的标题列表。工具条最右侧的按钮控制这栏的显隐，左侧边缘可拖动，宽度在 190–520px 之间。查找放进这同一列，不另做边栏，也不使用 v5md 里那条左侧大纲。

## 目标

v5notes 右侧栏增加「查找」视图，和现有「大纲」视图共用这一列，一次只显示一个。查找的样子对齐 VS Code：查找行默认可见，替换行可展开，旁边有上一个、下一个和结果计数，并提供区分大小写、全词、正则三个开关。

`⌘F` / `Ctrl+F` 打开这一列并切到查找，不再打开编辑器顶部的查找表单。playground 没有这条外置栏，仍使用编辑器自己的查找表单。

## 布局

栏的位置、宽度、拖动条和工具条上的显隐按钮都保持现在的右侧大纲栏。栏头从单独的「大纲」改成两个标签：

```text
工具条                                          [大纲按钮]
┌──────────────────────────┬─────────────┐
│                          │ 大纲   查找  │
│          正文             ├─────────────┤
│                          │  当前视图     │
└──────────────────────────┴─────────────┘
```

大纲按钮仍只展开或收起整列，不改变当前标签。默认宽度仍是现在的大纲宽度。查找表单在这一列里排下；列太窄时输入框收缩，三个开关保持可见。

## 查找视图

收起替换时：

```text
[ 查找内容……………… ]  Aa  ab  .*  ↑  ↓
                    2/5
▸ 替换
```

展开替换时：

```text
[ 查找内容……………… ]  Aa  ab  .*  ↑  ↓
                    2/5
▾ 替换
[ 替换为………………… ]  替换  全部替换
```

三个开关的含义：

| 开关 | 含义 | 默认 |
| --- | --- | --- |
| Aa | 区分大小写 | 关闭，不区分大小写 |
| ab | 全词匹配 | 关闭 |
| .* | 把查找词当作正则 | 关闭 |

这是相对现在 `indexOf` 的行为变化：默认不再区分大小写，和 VS Code 一致。三个开关都关掉时，查找就是不区分大小写的字面量。

交互：

- `⌘F` / `Ctrl+F`：显示右侧栏，切到查找，聚焦查找框并选中已有文字。查找已经聚焦时，再按一次只重新选中文字。
- `⌘H` / `Ctrl+H`：同样打开查找，并展开替换行，焦点留在查找框。编辑器里现有的 `⌘⇧H` 仍然是高亮，两者不冲突。
- Enter 和 ↓ 是下一处，Shift+Enter 和 ↑ 是上一处。到文末后从开头继续，到开头后从文末继续。
- 查找框为空时不查找、不计数、不替换。
- 有匹配时显示 `当前/总数`，例如 `2/5`。没有匹配时显示「无结果」。
- 当前匹配由编辑器标成选区，并滚进可见区域。本期不高亮其余匹配。
- 「替换」替换当前这一处并跳到下一处。「全部替换」替换全部匹配，记为一步撤销。
- 在查找框或替换框按 Esc：回到大纲视图，右侧栏保持打开，焦点回到正文。
- 在两个标签之间切换时，查找词、替换词和三个开关都保留。
- 预览时查找和上下跳转可用。替换框、替换和全部替换不可用，因为预览不允许改文档。进入编辑后再替换。

## 匹配规则

规则放在 `@v5md/core`。v5notes 的查找视图只提交查找词、替换词和三个开关，并展示核心返回的范围、序号、总数和错误。

查找选项：

- `caseSensitive`：是否区分大小写。
- `wholeWord`：是否要求全词。
- `regexp`：查找词是否是正则。

词字符是 Unicode 字母、数字和下划线，汉字算词字符。全词表示匹配开始之前要么是文首、要么不是词字符，匹配结束之后要么是文末、要么不是词字符。因此「笔记」不会命中「云笔记」。正则打开时，先按用户的正则取出候选，再用同一条边界规则过滤，不把用户的正则包进 `\b`。

正则使用 JavaScript `RegExp`。不区分大小写时带 `i`。非法正则不产生匹配，也不执行替换，核心把错误交回视图，查找框显示「正则无效」。`a*` 这类零宽度匹配向后查找时至少前进一个字符，避免停在原地。全部替换时同样跳过零宽度匹配。

替换词只在正则打开时解释 `$$`、`$&`、`$1` 到 `$9`。字面量模式下，`$` 就是普通字符。

向前查找从当前选区之后开始；如果当前选区正好是一条匹配，就从这条匹配的末尾开始。向后查找对称处理。两种方向都回绕。返回值包含匹配范围、从 1 开始的序号和总数，视图用它显示 `2/5`。没有匹配时返回空。

## 快捷键怎么交到右侧栏

焦点在编辑器里时，按键先到达 v5md。编辑器增加一个可选的查找回调。v5notes 传入这个回调，用来打开自己的右侧栏并切到查找。回调存在时，`⌘F` / `Ctrl+F` 和 `⌘H` / `Ctrl+H` 只调用回调，不打开顶部查找表单。

没有回调时，编辑器保持现在的顶部查找表单。playground 因此不用改布局。

v5notes 不在窗口上抢先截获这两个快捷键。否则编辑器库自己的查找命令会和宿主各做一遍。

## 归属

| 能力 | 位置 |
| --- | --- |
| 大小写、全词、正则、回绕、序号、总数、替换和撤销 | `@v5md/core` |
| 查找快捷键，以及有宿主回调时不再打开顶部表单 | `@v5md/view` |
| 右侧栏、大纲视图、查找视图、三个开关、栏的显隐和宽度 | v5notes |
| 预览下禁用替换 | v5notes 的查找视图按当前是否在编辑模式决定 |

v5notes 继续隐藏编辑器内置大纲，继续使用现在这条右侧栏。不把大纲列表移回 v5md，也不在编辑器里再做一条右侧栏。

## 测试

核心测试覆盖：默认不区分大小写、打开后区分大小写、汉字全词、正则分组替换、非法正则、零宽度正则不会死循环、全部替换一步撤销。

编辑器测试覆盖：没有查找回调时 `⌘F` 仍打开顶部表单；有回调时只调用回调，顶部表单不出现。

v5notes 测试覆盖：快捷键回调会打开右侧栏并切到查找，Esc 回到大纲，预览时替换控件不可用。匹配是否正确由 v5md 的测试负责。
