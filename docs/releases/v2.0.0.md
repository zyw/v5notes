# V5Notes 2.0.0 发布说明

[简体中文](v2.0.0.md) · [English](v2.0.0.en.md)

**发布日期：** 2026-11-14

把想法留在自己的服务器上。

V5Notes 2.0.0 是一次整体换代：后端、管理后台与桌面客户端全部重建，并下线 1.x 旧目录。请按当前仓库 README 部署与升级，不要沿用 1.x 的启动与建表方式。

## 亮点

- **全新三端**：`v5notes2`（Java 21 / Spring Boot 4.1）、`v5notes-admin2`（Vue 3.5）、`v5notes-client2`（Tauri 2）
- **桌面写作**：目录与笔记树、预览与编辑同实例切换、专注模式、大纲、查找替换、图片库、PDF / HTML 导出
- **删改可回**：回收站保留 30 天；笔记历史版本可预览并恢复
- **社交登录**：支持 Gitee、GitHub；可绑定与解绑；桌面端 Deep Link 回调
- **试用配额**：自助注册与社交开户账号按存储与试用期限制；管理端可查看空间占用
- **主题与多语言**：应用级浅色 / 深色主题；简体中文、繁体中文、英文
- **部署与官网**：Docker Compose 一键拉起；新增官网与 OAuth 回调落地页；桌面端支持应用内更新

## 破坏性变更

- 移除 `v5notes`、`v5notes-admin`、`v5notes-client`（1.x Electron 客户端与旧管理后台）
- 数据库由 Flyway 管理；生产环境请使用 2.0 配置与迁移，勿混用 1.x SQL 手工建表流程
- 桌面端需安装新版 Tauri 应用，无法与 1.x Electron 客户端混用

## 升级建议

1. 备份数据库与上传文件目录
2. 按 README 部署 `v5notes2` 与 `v5notes-admin2`
3. 安装新版桌面客户端，重新连接服务器并登录
4. 若启用社交登录，配置 Gitee / GitHub 的 Client ID、Secret 与回调地址
