# V5Notes 2.0.1 发布说明

[简体中文](v2.0.1.md) · [English](v2.0.1.en.md)

**发布日期：** 2026-11-15

把想法留在自己的服务器上。

V5Notes 2.0.1 是 2.0.0 之后的维护与增强版本，聚焦消息推送、注册通知、桌面 Deep Link 单实例，以及管理端消息展示修复。可在现有 2.0.0 部署上升级；请先备份数据库与上传目录，并执行 Flyway 迁移。

桌面端应用内更新说明原稿：[v5notes-client2/releases/2.0.1.md](../../v5notes-client2/releases/2.0.1.md)。

## 亮点

- **消息推送**：管理端与桌面客户端支持实时消息 / 通知；侧栏消息铃铛；WebSocket 使用一次性连接票据，避免把 JWT 放进 URL
- **消息盒子 HTML**：管理端通知正文按白名单消毒后渲染，公告富文本不再显示为裸标签
- **注册通知管理员**：客户端注册（邮箱注册与第三方开户）成功后可异步邮件通知管理员；参数设置可开关
- **桌面单实例**：集成 Tauri 单实例插件，重复启动时把 Deep Link 交给已运行实例，避免多开打断社交登录回调
- **配置与发布**：客户端环境变量整理；API 镜像发布工作流支持手动触发与更清晰的版本解析

## 修复

- 管理端「消息盒子」中通知公告内容把 `<p>...</p>` 当纯文本显示的问题
- 社交登录 Deep Link 在已有客户端实例时可能被新进程吞掉的问题（依赖单实例接管）

## 参数与升级注意

新增系统参数（默认关闭通知）：

| 参数键 | 说明 |
| --- | --- |
| `client.account.registerNotifyAdmin` | `true` 开启客户端注册成功邮件通知管理员 |
| `client.account.registerNotifyAdminEmail` | 收件邮箱（可多个，逗号 / 分号分隔）；为空则回退超级管理员用户邮箱；仍为空则不发送 |

发信为异步事件，失败只记日志，**不影响注册成功**。需已启用邮件服务（`mail.enabled=true`）。

升级步骤：

1. 备份数据库与上传文件目录
2. 部署本版 `v5notes2`、`v5notes-admin2`，确认 Flyway 执行到含 `V16__client_register_notify_admin` 的迁移
3. 安装 / 更新桌面客户端至 2.0.1（macOS 按芯片选择 Apple 或 Intel 安装包；应用内更新会匹配本机架构）
4. 如需注册通知：在参数设置中打开开关并配置收件邮箱（或确保 admin 用户已填写邮箱）
