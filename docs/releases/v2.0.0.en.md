# V5Notes 2.0.0 Release Notes

[简体中文](v2.0.0.md) · [English](v2.0.0.en.md)

**Release date:** 2026-11-14

Keep your ideas on your own server.

V5Notes 2.0.0 is a full-stack rewrite of the API, admin console, and desktop client. The 1.x directories have been removed. Deploy and upgrade using the current repository README—do not reuse 1.x startup or schema workflows.

## Highlights

- **New stack**: `v5notes2` (Java 21 / Spring Boot 4.1), `v5notes-admin2` (Vue 3.5), and `v5notes-client2` (Tauri 2)
- **Desktop writing**: combined directory-and-note tree, shared preview/edit editor instance, focus mode, outline, find and replace, image library, PDF / HTML export
- **Safe delete and restore**: trash retained for 30 days; note revision history with preview and restore
- **Social sign-in**: Gitee and GitHub; bind and unbind; desktop Deep Link callbacks
- **Trial quotas**: self-registered and social-created accounts limited by storage and trial period; admin can inspect storage usage
- **Theme and i18n**: app-level light / dark themes; Simplified Chinese, Traditional Chinese, and English
- **Deploy and site**: Docker Compose one-command setup; marketing site and OAuth callback landing page; in-app desktop updates

## Breaking changes

- Removed `v5notes`, `v5notes-admin`, and `v5notes-client` (1.x Electron client and legacy admin)
- Schema is managed by Flyway; use 2.0 configuration and migrations in production—do not mix 1.x hand-applied SQL
- Install the new Tauri desktop app; it is not interchangeable with the 1.x Electron client

## Upgrade guide

1. Back up the database and upload directory
2. Deploy `v5notes2` and `v5notes-admin2` following the README
3. Install the new desktop client, reconnect to the server, and sign in
4. If social login is enabled, configure Gitee / GitHub Client ID, Secret, and callback URLs
