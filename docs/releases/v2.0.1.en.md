# V5Notes 2.0.1 Release Notes

[简体中文](v2.0.1.md) · [English](v2.0.1.en.md)

**Release date:** 2026-11-15

Keep your ideas on your own server.

V5Notes 2.0.1 is a maintenance and enhancement release after 2.0.0. It focuses on realtime messaging, registration admin alerts, desktop single-instance Deep Links, and a message-box HTML rendering fix. You can upgrade from an existing 2.0.0 deployment; back up the database and upload directory first, then run Flyway migrations.

In-app updater notes source: [v5notes-client2/releases/2.0.1.md](../../v5notes-client2/releases/2.0.1.md).

## Highlights

- **Realtime messaging**: admin and desktop clients receive live messages / notices; WebSocket connections use a one-time ticket so JWTs are not placed in the URL
- **Message box HTML**: admin notice bodies are sanitized then rendered, so announcement rich text is no longer shown as raw tags
- **Register → admin email**: after client registration (email signup or social account creation), optionally email administrators asynchronously; controlled by system settings
- **Desktop single instance**: Tauri single-instance plugin hands Deep Links to the running app instead of spawning another process that can break social-login callbacks
- **Config and publish**: cleaner client env vars; API image workflow supports manual runs and clearer version parsing

## Fixes

- Admin “Message Box” showed notice content like `<p>...</p>` as plain text
- Social-login Deep Links could be swallowed by a second process when the desktop app was already open (addressed via single-instance handoff)

## Settings and upgrade notes

New system settings (notification off by default):

| Key | Description |
| --- | --- |
| `client.account.registerNotifyAdmin` | `true` enables admin email on client registration success |
| `client.account.registerNotifyAdminEmail` | Recipient address(es), comma/semicolon separated; if empty, falls back to the super-admin user’s email; if still empty, nothing is sent |

Mail is sent asynchronously via an event listener. Failures are logged only and **do not block registration**. Mail service must be enabled (`mail.enabled=true`).

Upgrade steps:

1. Back up the database and upload directory
2. Deploy this `v5notes2` and `v5notes-admin2` build; confirm Flyway applies migrations through `V16__client_register_notify_admin`
3. Install / update the desktop client to 2.0.1
4. To enable registration alerts: turn on the setting and set a recipient email (or ensure the admin user has an email)
