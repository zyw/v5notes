# V5Notes 2.0.2 Release Notes

[简体中文](v2.0.2.md) · [English](v2.0.2.en.md)

**Release date:** 2026-11-16

Keep your ideas on your own server.

V5Notes 2.0.2 is a maintenance and enhancement release after 2.0.1. It focuses on desktop note organization (move / drag-and-drop), FTP/FTPS file storage with per-user path isolation, profile signatures, and environment variables for OAuth callback bases. You can upgrade from an existing 2.0.0 / 2.0.1 deployment; back up the database and upload directory first. This release adds **no new Flyway migrations**.

In-app updater notes source: [v5notes-client2/releases/2.0.2.md](../../v5notes-client2/releases/2.0.2.md).

## Highlights

- **Note move and drag-and-drop**: drag notes into folders in the desktop sidebar, or use the Move dialog; unsaved drafts are handled before the move
- **FTP / FTPS storage**: admin file config supports FTP and FTPS (default ports and an FTPS toggle); built on Apache Commons Net with Chinese path encoding support
- **Per-user path isolation**: upload relative paths are forced under the current user directory (`{userId}/…`) to avoid cross-user file mix-ups
- **Profile signature**: the desktop profile can read/write a signature (reuses the user `remark` field); no schema change
- **OAuth callback env vars**: `justauth.address` / `justauth.client-address` can be overridden with `V5NOTES_JUSTAUTH_ADDRESS` and `V5NOTES_JUSTAUTH_CLIENT_ADDRESS`; Docker Compose and `env.example` are updated
- **OAuth landing**: `v5notes-oauth-landing` adds an Nginx example for same-port reverse proxy with the admin UI, documenting `/social-callback` and brand-icon paths
- **Ops**: SQL logs can go to a dedicated rolling file `sys-sql.log`; unused dependency declarations cleaned from the parent POM

## Fixes and improvements

- More accurate default ports when switching storage types in file config; more reliable client cache refresh after storage-type changes
- Clearer drop-target highlighting in dark theme when reorganizing notes in the sidebar

## Settings and upgrade notes

New / useful environment variables:

| Variable | Purpose |
| --- | --- |
| `V5NOTES_JUSTAUTH_ADDRESS` | Admin OAuth callback base (`justauth.address`) |
| `V5NOTES_JUSTAUTH_CLIENT_ADDRESS` | Desktop client OAuth callback base (`justauth.client-address`) |

Upgrade steps:

1. Back up the database and upload directory
2. Deploy this `v5notes2` and `v5notes-admin2` build (no new migrations; confirm a clean startup)
3. Install / update the desktop client to 2.0.2 (on macOS pick the Apple Silicon or Intel build; in-app updates match the host architecture)
4. If you use social login: set the JustAuth env vars for your domains and register the matching callback URLs in the Gitee / GitHub apps
5. If you switch to FTP/FTPS: fill host, port, and credentials in admin “File Config”, and enable FTPS when needed
