# V5Notes 2.0.2 发布说明

[简体中文](v2.0.2.md) · [English](v2.0.2.en.md)

**发布日期：** 2026-11-16

把想法留在自己的服务器上。

V5Notes 2.0.2 是 2.0.1 之后的维护与增强版本，聚焦桌面端笔记整理、文件存储 FTP/FTPS 与用户目录隔离、个人签名，以及 OAuth 回调基址的环境变量化。可在现有 2.0.0 / 2.0.1 部署上升级；请先备份数据库与上传目录。本版**无新增 Flyway 迁移**。

桌面端应用内更新说明原稿：[v5notes-client2/releases/2.0.2.md](../../v5notes-client2/releases/2.0.2.md)。

## 亮点

- **笔记移动与拖放**：桌面端侧栏支持将笔记拖入目录，也可通过菜单打开「移动」对话框选择目标；切换前会先处理未保存草稿
- **FTP / FTPS 存储**：管理端文件配置支持 FTP、FTPS（可切换默认端口与启用 FTPS）；基于 Apache Commons Net，兼容中文路径编码
- **用户目录隔离**：上传相对路径强制落在当前用户目录下（`{userId}/…`），避免多用户文件串目录
- **个人签名**：客户端个人资料可读写签名（复用用户 `remark` 字段），无需改表
- **OAuth 回调环境变量**：`justauth.address` / `justauth.client-address` 可通过 `V5NOTES_JUSTAUTH_ADDRESS`、`V5NOTES_JUSTAUTH_CLIENT_ADDRESS` 覆盖；Docker Compose / `env.example` 已同步
- **社交登录落地页**：`v5notes-oauth-landing` 补充与管理端同端口反代的 Nginx 示例，明确 `/social-callback` 与品牌图标路径
- **运维**：SQL 日志可写入独立滚动文件 `sys-sql.log`；后端父 POM 清理未使用依赖声明

## 修复与改进

- 文件配置切换存储器类型时默认端口自动填充更准确；存储类型变更后的客户端缓存刷新更可靠
- 暗色主题下拖放目标高亮，侧栏整理笔记更清晰

## 参数与升级注意

新增 / 常用环境变量：

| 变量 | 作用 |
| --- | --- |
| `V5NOTES_JUSTAUTH_ADDRESS` | 管理端 OAuth 回调基址（对应 `justauth.address`） |
| `V5NOTES_JUSTAUTH_CLIENT_ADDRESS` | 笔记客户端 OAuth 回调基址（对应 `justauth.client-address`） |

升级步骤：

1. 备份数据库与上传文件目录
2. 部署本版 `v5notes2`、`v5notes-admin2`（本版无新迁移，确认服务正常启动即可）
3. 安装 / 更新桌面客户端至 2.0.2（macOS 按芯片选择 Apple 或 Intel 安装包；应用内更新会匹配本机架构）
4. 若使用第三方登录：按部署域名设置上述 JustAuth 环境变量，并在 Gitee / GitHub 应用中登记对应回调 URL
5. 若改用 FTP/FTPS：在管理端「文件配置」中填写主机、端口、账号，并按需开启 FTPS
