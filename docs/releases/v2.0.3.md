# V5Notes 2.0.3 发布说明

[简体中文](v2.0.3.md) · [English](v2.0.3.en.md)

**发布日期：** 2026-11-17

把想法留在自己的服务器上。

V5Notes 2.0.3 是 2.0.2 之后的维护与增强版本，聚焦桌面端笔记拖动手感、编辑器主题切换、v5md 升级，以及桌面安装包的一站式发布流水线。可在现有 2.0.x 部署上升级；请先备份数据库与上传目录。本版**无新增 Flyway 迁移**，后端 / 管理端若未改动可继续沿用 2.0.2 部署，但桌面客户端需更新至 2.0.3。

桌面端应用内更新说明原稿：[v5notes-client2/releases/2.0.3.md](../../v5notes-client2/releases/2.0.3.md)。

## 亮点

- **拖动与单击分离**：侧栏笔记按下先进入「可拖动」光标，超过阈值才真正拖动；未超过阈值仍可单击打开，拖动结束后不会误触打开
- **拖动提示**：笔记行标题增加「单击打开，按住拖动」提示（中 / 英 / 繁）
- **编辑器主题**：命令面板可选择跟随应用主题（自动），或固定为 Paper、GitHub、Nord、Tokyo Night、Catppuccin、One Dark、Dracula、Solarized Light / Dark；选择会持久化，主编辑区与历史预览共用同一主题
- **v5md 0.0.6**：桌面端改为从 npm 锁定 `@v5md/core` / `@v5md/view` / `@v5md/vue@0.0.6`，不再依赖仓库内 vendor 压缩包
- **桌面发布流水线**：新增 `publish-desktop.yml`，推送 `v*` tag 或手动运行即可构建 macOS（Apple / Intel）与 Windows x64 安装包并上传；`publish-update-feed` 不再监听 tag，避免与打包并发时生成不完整的 `latest.json`

## 修复与改进

- 暗色主题下编辑器外观更多交由 v5md 主题体系，客户端冗余暗色覆盖减少
- 应用内更新清单与三端产物对齐：三份更新包（及 `.sig`）齐全后再写入 / 重算 `latest.json`

## 升级注意

本版无新增系统参数或数据库迁移。

升级步骤：

1. 备份数据库与上传文件目录（若同时升级服务端）
2. 服务端 / 管理端：可继续使用 2.0.2；若一并发布本仓库最新构建，确认服务正常启动即可（无新 Flyway）
3. 安装 / 更新桌面客户端至 2.0.3（macOS 按芯片选择 Apple 或 Intel 安装包；应用内更新会匹配本机架构）
4. 开发者升级编辑器能力时，请发布并锁定对应 `@v5md/*` npm 版本；本地联调仍可用 `V5MD_LOCAL_ROOT`

## 技术栈

与 2.0.0–2.0.2 相同，桌面编辑器依赖升级为：

| 组件 | 版本 |
| --- | --- |

| 管理后台 | Vue 3.5、Vite 8、Element Plus |
| 桌面客户端 | Vue 3.5、Tauri 2、`@v5md/*` 0.0.6 |
| 数据 | MySQL 8.4 / PostgreSQL、Redis 7.4 |
