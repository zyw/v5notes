# 设置页 · 六候选与三方向

参考物：v5notes-client2 的设置弹窗（ref-client2.png，1440×900，实际截取）。六张缩略图见 thumbs.png。

## 六候选

### 01 · 案头（已做成完整版 dir-1.html）

- **逻辑与来源**：最佳设计师 A｜吕敬人书籍设计（《朱熹千字文》《怀袖雅物》；见 style-specimens/east/01）。
- **借的是什么**：版心呼吸（上提、靠订口、地脚大）、页边目录、极细规则线、朱砂只做一处（本版落在印章、节号与 active nav 上）；标题用宋体，正文用无衬线，元信息用等宽。
- **主角素材**：正文本身；主题预览与库色条是唯一的图形，均为 CSS。
- **骨架**：左侧 sticky 目录（01–08）+ 右侧单列长文；每节以「节号 + 衬线标题 + 一句导语」开场，账号是唯一一张 sheet。
- **胆量花在哪**：整页没有卡片堆叠，只有一条贯穿的竖线与页边目录；让设置页像一本可以翻的册子。
- **form 来自内容的哪里**：Vault 是本地文件夹里的「库」，目录 + 册页是它最自然的信息形态；不是把页面做成道具。

### 02 · 仪器（备选，未做完整版）

- **逻辑与来源**：最佳设计师 B｜Dieter Rams / Braun 功能主义（通用设计原则，不对应单件作品）。
- **借的是什么**：标签在上、读数在下、单一指示灯、严格网格、等宽序列号；每个模块是一条可读的「控制条」。
- **主角素材**：状态读数与刻度；无图。
- **骨架**：顶部标题 + 横向章节 tab + 2 栏模块网格，模块用 1px 线而非圆角卡片。
- **胆量花在哪**：把所有说明压成「标签 / 读数 / 单位」三件套，像一台安静的仪器。
- **form 来自内容的哪里**：设置本身就是一组可核对的状态；Rams 的「少但更好」正好对应本地优先的克制。

### 03 · 工作台（已做成完整版 dir-2.html）

- **逻辑与来源**：现实参照 A｜v5notes-client2 设置弹窗（同一产品家族的现有实现，已截图并逐条拆过 CSS）。
- **借的是什么**：侧栏 + 内容区、面板头 23px 图标 chip + 12.5px 粗标题、渐变面板底、1px 暖灰边框、preference row + 32×18 switch、页脚版本行；把弹窗的密度扩到整页。
- **主角素材**：四格状态条（本地库 / 账号 / 同步 / 安全模式）+ 面板里的真实控件。
- **骨架**：232px 侧栏 + 主区；主区顶部搜索、四格状态条、12 栏面板网格（7/5、4/4/4、7/5、12）。
- **胆量花在哪**：状态条把「本地优先」变成可读的四格硬件式读数；其余仍是 client2 的克制面板。
- **form 来自内容的哪里**：设置是「现在是什么状态」+「要改什么」；状态条先回答前者，面板回答后者。

### 04 · 索引（备选，未做完整版）

- **逻辑与来源**：现实参照 B｜Raycast Settings 的「可搜索设置列表」形态（本次未现场截图，仅按桌面设置通例归纳，故只做备选）。
- **借的是什么**：⌘K 搜索、键盘上下选择、分区就地展开、每行右侧显示当前值；把长页折成一张可检索的索引。
- **主角素材**：搜索框与当前值文本。
- **骨架**：单列 720px，顶部品牌行 + 搜索 + 可展开分区行；没有常驻侧栏。
- **胆量花在哪**：设置不再是页，而是一个命令面板；熟练用户几乎不用滚。
- **form 来自内容的哪里**：8 节里真正高频的只有外观、账号、同步；索引把低频项收起来。

### 05 · 白盒（备选，未做完整版）

- **逻辑与来源**：秒数轮盘｜网页 #20 日式留白白盒画廊（原研哉 / Cosmos / Aesop；style-specimens/web/20）。
- **借的是什么**：近白纸面、极淡发丝线、极小书眉、巨大留白、内容自己提供层次；UI 退到背景。
- **主角素材**：字号与留白；无图。
- **骨架**：居中 720px 单列，顶部只有书眉与标题，每节一条细线 + 两行说明，控件贴右。
- **胆量花在哪**：把设置页做到几乎没有「界面」，只剩文字和一条线。
- **form 来自内容的哪里**：本地优先是一种安静；白盒把「不打扰」做成版式。

### 06 · 书页（已做成完整版 dir-3.html）

- **逻辑与来源**：秒数轮盘｜中文与东亚 #2 宋刻本版式 + #3 民国书衣（style-specimens/east/02、03），并沿用吕敬人的版心与朱印。
- **借的是什么**：对开页、版心偏订口、页边目录、朱印章节号、页脚 folio、纸页叠边与订口阴影；控件仍是 client2 的紧凑 row / switch。
- **主角素材**：书页本身与朱印；主题预览、库色条是页面内的小图。
- **骨架**：左页目录（8 章）+ 右页单章内容；一次只读一章，上一章/下一章 + 方向键翻页。
- **胆量花在哪**：设置被做成一本真正的对开册子，用翻页替代长滚；这是三版里唯一「用力」的一版。
- **form 来自内容的哪里**：Vault 是一册本地笔记；设置是这册书的版权页与目录，而不是一个 dashboard。

## 为什么做这三张完整版

- **01 案头**：最强 editorial 版，保留长页但给出目录，和现有 Vault 暖纸/宋体身份最连续。
- **03 工作台**：最直接回应「参考 v5notes-client2」，面板语言与 client2 同源，落地风险最低。
- **06 书页**：结构最大胆，把 8 节变成 8 章，解决长页问题；适合想要「记忆点」的方向。

未做的 02 仪器、04 索引、05 白盒保留在 thumbs.png 中；02 的仪表读数、04 的 ⌘K 索引、05 的极简白盒都可以在选定方向上吸收局部。

## 验证

- 三版均用 headless Chrome 在 1280×900 渲染；整页截图：dir-1.png（1280×3801）、dir-2.png（1280×1281）、dir-3.png（1280×900）。
- CDP 控制台 0 报错；01/03 的目录 scroll-spy、02 的搜索过滤、06 的翻页/键盘/表单交互均实测。
- design_lint.py check 因本机未装 Python playwright 被跳过；改用截图与 CDP 人工核对。
