# 设置页美化 · 设计 spec

## 产品与场景

V5Notes Vault 是本地优先的桌面笔记库（Tauri）。设置页是低频但高密度的控制面板：服务器与账号、双产品边界、备份迁移、官方发布预览、外观、插件与安全、插件目录、安装信息，共 8 节。

当前实现是 640px 单列长页（约 1032×4064）：所有 section 同一权重，账号区占据首屏，长页缺少导航；大量说明文字与控件挤在同一条线上。

## 受众

- 主要：已打开本地库、未登录、以本地写作为主的用户。需要快速改主题、确认备份边界、管理插件。
- 次要：登录后需要绑定同步、查看设备/额度的用户（本次方向稿以未登录态为主，登录态在组件层保留）。

## 目标

1. 8 节内容在长页里可被一眼定位；导航与内容的关系比现状更明确。
2. 账号表单在首屏可完成；危险/不可逆动作（迁移、安全模式）有清楚边界。
3. 与 v5notes-client2 的设置弹窗同一套语言：暖纸、墨绿、衬线标题、细分隔线、紧凑 preference row、switch、面板头图标。
4. 不丢掉任何现有文案、控件、状态与可访问语义；不新增后端依赖。

## 统一输出格式

- 桌面应用设置页，基准视口 1280×900；长页方向给整页截图，书页方向给 900px 视口截图。
- 三版共用同一份内容与同一套品牌色（暖纸 #f1ecdf / 面板 #fbf7ee / 墨绿 #2f5b48 / 朱砂 #8a3b2e）。
- 字体：Noto Serif SC / Songti SC（标题），DM Sans / PingFang SC（UI），SF Mono（元信息）。
- 固定演示状态：未登录、已打开示例库「晴耕雨读」、安全模式关闭、默认主题、跟随系统、寒露·竹青库色。

## 内容清单

01 账户（官方/自定义服务器、账号、密码、登录、Gitee/GitHub、同步锁定说明）
02 帮助·双产品（Cloud 与 Vault 的边界、两个产品的名称）
03 备份与迁移（整库 zip 仅备份、迁移显式确认）
04 官方发布 / 分享（站点标题、私有/不公开链接/公开、官方通道预览）
05 外观（默认/暮色主题、跟随系统/浅色/深色、6 个节气库色）
06 插件与安全（安全模式、已安装扩展、命令）
07 插件目录（刷新、Safe Fetch Demo、Catalog Moss）
08 关于本机（产品、Bundle ID、Deep link、扩展阶段）

## 约束

- 使用现有 token：--bg/--panel/--ink/--muted/--line/--accent/--vault/--radius-*；暗色与暮色主题仍要能覆盖。
- 不编造额度、文件数、设备数；示例库名只作为演示状态。
- 正文与控件保持可读：本次原型正文 12.5–14px，标签 10–12px；实际落地时按 WebView 字号再校准。
- 保留现有 focus-visible、role="switch"、aria-pressed、disabled 状态。

## 素材

- 品牌图标：src/assets/brand-icon.png（base64 内嵌）。
- 主题预览：纯 CSS 缩略页，不用产品截图。
- 库色：直接取 src/appearance/vaultColors.ts 的 6 个色值与节气名。
- client2 参考截图：ref-client2.png（本地 Vite + headless Chrome 截取）。

## 验收

- 1280×900 下无横向滚动；三版截图均无控制台报错。
- 能通过一次点击到达任一节；账号表单、主题、库色、可见性、switch 均能操作。
- 与 client2 并排看像同一产品家族，但比现有设置页更有秩序。
