第一章 · 账户

账户

同一账号可登录两个客户端；Cloud 笔记与 Vault 库默认不是同一份数据。Vault 始终在本机文件夹。

当前：官方服务器 · deviceType=vault_client · 未登录仍可纯本地建库、写笔记与搜索。

登录后可绑定当前本地库并增量同步。
未登录时仍可继续本地编辑；失败项会进入重试队列。

账号可选未登录仍可建库、写笔记与搜索。
密码不落盘仅用于换取令牌，不写入本机偏好。
双客户端同一账号可登录 Cloud 与 Vault。

第二章 · 帮助

帮助 · 双产品

两件产品共用一套账号，但笔记空间分开。登录同一账号不会自动合并两边内容。

Cloud 在服务端目录树；Vault 在本机文件夹。
V5Notes 云笔记（Cloud）与 V5Notes Vault 共用账号体系，但笔记空间分开：Cloud 用 /client/notes*；Vault 用本机文件夹 + 可选 /vault/v1 同步。登录同一账号不会把两边笔记自动合并。

第三章 · 备份

备份与迁移

整库 zip 仅作备份与迁机，不是日常同步。日常 Sync 走文件级增量；请勿用 zip 覆盖当作 Sync。

备份包含笔记与附件，以及 .v5notes/vault.json 等库元数据；排除本地 trash、sync-state、index.sqlite 与临时文件。

第四章 · 发布

官方发布 / 分享

站点发布与分享是 V5Notes 官方产品能力，不向社区第三方插件开放。插件无法申请 publish:*。

当前为官方通道预览：可填写站点标题与可见性偏好并保存在本机；完整站点托管与公开 URL 将随后续官方增值上线，不会变成社区插件 API。
