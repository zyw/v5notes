# 2.0.0

V5Notes 2.0.0 是一次整体换代：后端、管理后台与桌面客户端全部重建。

## 亮点

- 全新三端：Java 21 / Spring Boot 4.1、Vue 3.5 管理后台、Tauri 2 桌面客户端
- 目录与笔记树、预览与编辑同实例切换、专注模式、大纲、查找替换、图片库、导出
- 回收站保留 30 天；笔记历史版本可预览并恢复
- 支持 Gitee、GitHub 登录，可绑定与解绑
- 自助注册与社交开户按存储与试用期限制
- 浅色 / 深色主题；简体、繁体、英文
- 应用内检查更新

## 破坏性变更

- 下线 1.x 的 `v5notes`、`v5notes-admin`、`v5notes-client`
- 数据库改由 Flyway 管理，请按当前 README 部署
- 需安装本版 Tauri 客户端，不可与 1.x Electron 客户端混用

## 升级

1. 备份数据库与上传目录
2. 部署 `v5notes2` 与 `v5notes-admin2`
3. 安装本版客户端并重新登录

完整说明见 [发布文档](https://github.com/zyw/v5notes/blob/dev/docs/releases/v2.0.0.md)。
