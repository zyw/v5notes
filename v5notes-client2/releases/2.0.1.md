# 2.0.1

V5Notes 2.0.1：消息推送、注册通知与桌面 Deep Link 单实例增强。

## 亮点

- 桌面端消息铃铛与实时推送（SSE / WebSocket 一次性票据连接）
- 客户端注册成功后可异步邮件通知管理员（参数设置可开关）
- 单实例接管 Deep Link，避免多开打断社交登录回调
- 管理端消息盒子正确渲染公告 HTML（消毒后展示）

## 修复

- 已运行客户端时 Deep Link / 社交登录回调可能被新进程打断
- 管理端通知正文显示裸 HTML 标签
