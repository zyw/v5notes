## 1 · 一句重述

用户要的不是「登录卡换个皮」：左侧那张「把想法，留在这里。」现在只是一句口号，看不出这是**能写三种模式、有一棵目录树、能回退历史版本的桌面 Markdown 笔记工具**；背景是一张静态渐变，没有活气。这次把左半边变成「产品自己在发光」，再给背景一套有主张、有呼吸的动效——但右边那列登录仍然必须一眼认得出、点得动。

## 3 · 方向卡（六张）

### K1 · 白 · 纸呼吸

- **逻辑与来源**：原研哉——『白』里「空」不是没有，是让素材自己说话；MUJI 的克制。参考的是他的**方法**（删到只剩材料与字、留白当构图），不是某张海报的外观。
- **借的是什么**：纸本色当底；版心偏左、天头小地脚大；页边注比正文小两号；线只留 1px 且不闭合；登录区去卡片化，只用一条竖发丝线跟左页分开。字号关系 1 : 2.6 : 7（注 / 正文 / 标题）。
- **主角素材**：程序化纸面——细噪点纤维 + 一束斜光 + 边缘极轻的暗角；上面是一段真的正在写的 Markdown（`十月的一个下午`），三种模式做成页眉上一排小字，历史版本做成纸边的一道细刻度。
- **骨架**：左页（占 62%）｜竖发丝线｜右登录窄栏；上沿齐一，下沿留白。
- **胆量花在哪**：**把登录卡的底、边、阴影全部拿掉**，只靠位置和一条线区分——整屏像一页摊开的纸，登录是纸上的一个栏位。
- **form 来自内容的哪里**：笔记产品的本质是一页纸；页面就该像纸，而不是像表单。
- **背景动效**：三层极慢的墨色晕染（青瓷→墨绿，alpha 0.03–0.07）在纸面下漂移，周期 28–36s；一束柔光从左上方缓慢呼吸；纸纤维噪点静态。鼠标 6px 视差。

### K2 · 版 · 三次套印

- **逻辑与来源**：服部一成——把印刷网点换成条纹、把套印偏差当成语言（2007 年「旗」海报起）；他的玩味只集中在一处，信息栏反而老实。
- **借的是什么**：三张「印版」错位叠放；标题叠 2–3px 的深青重影；信息栏 12px 小字、两列严格对齐；色块只用三块（墨绿/深青/青瓷）；标题与信息栏字号比 ≈ 7 : 1。
- **主角素材**：**同一段笔记的三次成像**——三张纸的印版，分别是「所见即所得」「源码」「预览」，各错位 10–14px，最前一张清晰可读，后两张只露出边和标题行。这是产品真实的三模式，不是装饰。
- **骨架**：左上标题（带错位重影）｜中左三张错位印版｜右下 2 列信息块（模式/目录/历史/专注）｜右侧登录卡。卡片保留，但压成「印刷品」：1px 深青边、8px 圆角、几乎无阴影。
- **胆量花在哪**：三张印版错位叠放 + 标题的套印重影；其余（信息块、登录卡）全部老实。
- **form 来自内容的哪里**：三种模式不是三个功能，是同一份 Markdown 的三种成像——套印偏差就是这个产品的结构。
- **背景动效**：水平细条纹以 0.4px/s 缓慢漂移（像印版微移），每 6s 一次极轻的「对版」脉冲：三张印版收拢 2px 再放开；纸面有静态网点。

### K3 · 光 · 阅读带（备选）

- **逻辑与来源**：iA Writer 的 Focus Mode——当前句高亮、其余退成灰；单栏、无 chrome（官方说明页已核实）。
- **借的是什么**：一栏到底、行宽 32 字、正文 17px/1.9；一条 2.2 行高的柔光带落在当前行；除当前行外文字降到 30% 对比。
- **主角素材**：一整屏正在被读的笔记，一行亮着；登录收成右下角一条没有背景的窄缝（只有发丝线）。
- **骨架**：单一文本栏（左，宽 560px）｜右下登录 320px｜其余留白。
- **胆量花在哪**：整屏几乎没有图形，只有一行会移动的光。
- **form 来自内容的哪里**：专注写作就是这个产品的真实功能（`.focus-mode`）。
- **背景动效**：光带以 9s 一行缓慢下移，到段尾回卷；背景纸色极缓的明度呼吸（±1.5%）。

### K4 · 架 · 笔记墙（备选）

- **逻辑与来源**：Are.na——安静的块面、1px 线、微型元信息，UI 退到内容后面（about 页已核实）。
- **借的是什么**：三列不等宽块面、块间 1px 线、每块右下角 10px 元信息；内容密度高但对比低。
- **主角素材**：8 条真实感的笔记碎片（会议三条线索 / 读书笔记 / 周记 / 产品灵感……），每条一段话，缓慢上浮、上下边缘渐隐。
- **骨架**：左侧笔记墙（占 64%，被上下边缘裁切）｜右侧登录卡浮在纸色上。
- **胆量花在哪**：没有主视觉，主角是一面墙；墙被画布裁掉，暗示「还有很多」。
- **form 来自内容的哪里**：云笔记的第二身份是「收藏与整理」，墙就是目录树摊平之后的样子。
- **背景动效**：墙 40s 一轮缓慢上浮，鼠标靠近时该列减速（视差）；块的墨色随位置极缓变化。

### K5 · 影 · 写作的波形

- **逻辑与来源**：秒数轮盘抽到网页第 8 号「电影感声波可视化」——片头式极简、满幅暗场、单条发光波形、一个渐变 accent。照规矩只借骨架与节奏，颜色收进品牌（墨绿/深青/青瓷），不改品牌去凑风格。
- **借的是什么**：全幅暗场 + 单条横贯的发光波形 + 巨字压低 + 片尾字幕式的 11px 字距标签；一个渐变只用一次。
- **主角素材**：一条随「打字」起伏的波形：基线是正文行，脉冲是落下的每个字；左侧巨字与波形共用一条基线。
- **骨架**：暗场铺满｜左巨字（`把想法，留在这里。`）｜波形横穿中下部｜右侧半透明登录板（背板模糊 + 1px 亮线）。
- **胆量花在哪**：全站唯一一次深色底；登录卡是玻璃，不是纸。
- **form 来自内容的哪里**：写作有节奏，敲下的每个字都是一次脉冲——波形就是键盘的声音。
- **背景动效**：波形持续 60fps 低频起伏（周期 7s），每 1.1s 一次「输入脉冲」沿波形传开；背景有极轻的青瓷雾光在左下呼吸；深底上有 0.02 alpha 的纸纹。

### K6 · 册 · 一页解剖（备选）

- **逻辑与来源**：秒数轮盘东亚第 12 号「日式生活杂志密排」——黄色马克笔下划线、粗黑格线数据格、红蓝手写注解、窄体书眉。
- **借的是什么**：双栏密排；黄马克笔只划标题的一半；2×2 粗线格各放一条特色；红笔写一句旁批；书眉 10px。
- **主角素材**：把「笔记的一页」做成杂志跨页——左边是标题 + 手写批注，右边四格解剖产品。
- **骨架**：双栏（55/45）｜细线分区｜登录卡在「订阅读者卡」的位置。
- **胆量花在哪**：马克笔与手写批注（玩味只在这一处）。
- **form 来自内容的哪里**：杂志会解剖一件东西怎么用；登录页也可以解剖这个产品。
- **背景动效**：马克笔从左到右缓慢「划」一次（12s 循环，回到起点时淡出）；格线以 1px 呼吸；纸面有静态网点。

## 4 · 三个完整版的取舍

1. **单看够好**：K1 的空、K2 的版、K5 的光，三张静态截图都立得住；K3 偏「功能演示」、K4 偏「内容站」、K6 密排在小尺寸容易糊。
2. **彼此不同**：K1 是纸的物理感（暖、静）；K2 是印刷的图形感（暖、响）；K5 是光的电影感（冷、暗）。骨架、温度、明度都不同，不是三套配色。
3. **不撞账本**：外观账本为空，本项目此前登录页只有静态渐变，没有撞车。
4. **不用力过头**：K2 的三张错位印版是唯一的大胆处，其余（信息块、卡片）老实；K5 的深底是唯一的大胆处，登录仍清晰可读。

## 5 · 三版共同的交互规格（与现状一致）

- 字段与文案同 `spec.md` 第 4 节；Enter 提交；busy 时按钮禁用并显示 `正在连接…`；error 时 `role="alert"` 显示 `用户不存在/密码错误`。
- 右上齿轮 36×36，打开现有设置弹窗（原型只需可点、有 hover/focus 态）。
- `prefers-reduced-motion` 全部静止；`?t=` 冻结时间用于截图（见 spec 6.1）。
- 375 宽单列：左区在上、登录在下，背景动效降密度但保留。

## 7 · 落地（2026-11-10 第二轮）

用户选定：**B 作浅色、C 作深色**，登录页加一个三态主题按钮。原话见 `direction-approved.md`。

### 怎么合成一页

两套主题共用同一份 DOM（标题 / 展示区 / 登录卡 / 信息条），只换令牌与两个专属图层：

| | 浅色（B） | 深色（C） |
| --- | --- | --- |
| 地面 | 奶油纸 #f4f0e2 + 细横纹漂移 + 半调网点 | 深墨绿 #0b2622 + 青瓷雾光呼吸 |
| 标题 | 墨色 + 3px 套印重影 | 纸色 + 青瓷第二行 |
| 展示区 | 三张错位印版（所见即所得 / 源码 ×2 / 预览 ×3） | 玻璃笔记板 + 青瓷波形（7s 起伏、行进亮点） |
| 登录卡 | 纸卡 8px 圆角、深青按钮 | 玻璃 14px 圆角、纸色按钮 |

- 主题按钮：`自动 / 浅色 / 深色` 单键循环，位于设置齿轮左侧；`auto` 跟随 `prefers-color-scheme` 并实时响应系统切换。
- 记住选择：`v5notes-login-theme`（只作用于登录页；登录后的工作区仍是现有暖白界面）。
- 动效全部 CSS/SVG：细纹 48s 漂移、印版 6s 对版脉冲、雾光 22s、波形 26s 漂移 + SMIL 行进点；`prefers-reduced-motion` 全停。
- 可访问性：主题按钮带 `aria-label` 与 `role="status"` 播报；焦点环、Tab 顺序（主题 → 设置 → 更改 → 用户名 → 密码 → 进入笔记）保留；`color-scheme` 随主题切换，离开登录页时还原浅色。
