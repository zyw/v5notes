# 编辑器顶部工具条 · 三方向设计记录

日期：2026-03-20　画布：1440 × 900　落点：`v5notes-client2/src/components/EditorPane.vue` + `src/styles/style.css`

## 1 · 起点（现状）

现状顶栏（来自截图与代码）把 6 个同等重量的东西排成一行：
`折叠栏 · 笔记/标题 · 已保存 · 编辑(模式) · 预览 · 专注写作 · 历史 · 保存(分裂菜单) · 大纲`，
下面再接一条 44px 的灰底格式条（Σ / x² B I U <> S 💡 / 复制）。

这一轮要新增 **字号、隐藏工具条、导出 ×4（HTML / PDF / Markdown / 图片）**，共 10 项功能进编辑态。
一排放不下，也不该排成一排——问题从"哪里放"变成"哪些该一直被看见"。

## 2 · form 五问（每个方向开工前先答）

| | A 三段式单行 | B 悬浮机具 | C 极简写作条 |
|---|---|---|---|
| 叙事角色 | 工作台上的控制面板 | 一张会自己让路的工具桌 | 一张只有纸的桌子 |
| 观众距离 | 手臂长度，随手可点 | 指尖，跟随正文 | 一步之外，需要时才伸手 |
| 视觉温度 | 中性偏冷，精密 | 中性偏暖，轻浮起 | 最冷，几乎无装饰 |
| 容量 | 高（10 项全可见） | 中（顶栏 7 + 胶囊 4 组） | 低（顶栏 5 + 面板 12） |
| 视觉母题 | 竖线分簇 | 胶囊 / 悬浮 | 细线与留白 |

## 3 · 三个方向

### A · 三段式单行（`v1-single-row.html`）
- 左侧身份簇；右侧三簇：视图（专注 / Aa / 历史）· 模式（编辑 | 源码 + 预览眼睛）· 交付（导出 / 保存分裂 / 大纲），用 1px 竖线分簇。
- 工具条开关长在格式条自己的右端（指向它收起的东西），收起后正文顶部留 22px 浅色把手，另配 ⌘/。
- 字号：Aa 弹出面板（步进 + 滑杆 + 四档预设 + 重置）。
- 导出：一个入口，四项带一句说明 + 扩展名 + "导出前自动保存"。
- 适合：以最小改动收编新功能，老用户零迁移。

### B · 悬浮机具（`v2-floating-capsule.html`）
- 顶栏只做文档级动作：标题、保存状态、专注、历史、工具条开关、导出、保存、大纲（48px）。
- 排版级动作（编辑 | 源码、8 个格式键、字号、预览）进一条 42px 悬浮胶囊，居中漂在正文列上方，sticky 吸顶。
- 隐藏工具条：开关在顶栏常驻；按下后胶囊**只收起排版键**，模式与字号留下——隐藏不等于失去入口。
- 专注：顶栏整条退场，右下角 HUD 保留保存状态 / 退出专注 / 目录。
- 适合：把编辑页做成写作工具，愿意用"浮层"换 44px 垂直空间。

### C · 极简写作条 + 命令面板（`v3-command.html`）
- 顶栏 46px：折叠栏、标题、⌘K 命令、预览、合并状态的保存按钮（干净＝"已保存"，脏＝"保存"）、···、大纲。
- 格式条降为一条无灰地的细线，贴着正文左缘；右端 Aa 与「隐藏」，隐藏后左上角留低对比「格式 ⌘/」。
- ⌘K：命令按 显示模式 / 视图 / 排版 / 导出 分组，带快捷键与当前状态（已显示）；并与模式联动过滤——当前模式的那一项自动消失，编辑专属项（源码、专注、工具条）在预览态隐藏，空掉的分组标题一并收起，顶部标明「当前 · 预览 · 只读」与可用条数。
- 适合：功能还会继续长，愿意做一次快捷键与命令面板的投入。

## 4 · 六格候选的取舍

| 候选 | 一句话 | 去向 |
|---|---|---|
| A1 三段式单行 | 身份 / 视图 / 交付，一排放完 | **出完整版** |
| A2 单行 + 溢出 | 模式降图标、导出进「···」 | 备选：省 60px，但导出变两步 |
| B1 悬浮机具 | 文档动作顶栏、排版动作胶囊 | **出完整版** |
| B2 双行分段 | 文件条 + 独立工具条 | 备选：最稳，但没解决 44px 灰带 |
| C1 极简 + 命令面板 | 顶栏四件事，其余 ⌘K | **出完整版** |
| C2 极简 + 控制台面板 | 一个「工具」按钮弹九宫格 | 备选：鼠标友好，但面板里再排一次版 |

## 5 · 十项功能的落点（速查）

见 `index.html` 的「十项功能分别落在哪」矩阵。要点：
- 模式切换在 A/B 都是可见控件，C 进命令面板（⌘1/2/3）。
- 字号在 A/B 都是「Aa + 当前值」弹出面板，C 在格式条右端 + ⌘K。
- 工具条开关：A 在格式条右端；B 在顶栏；C 在格式条右端 + 命令面板。三版都保留第二条回退路径。
- 导出：A/B 是顶栏一个带说明的菜单（4 项）；C 把导出整条从顶栏撤掉，只在命令面板里给四条独立命令（各带扩展名）。
- 预览：A/B 是眼睛图标；C 因为撤掉了导出，把顶栏唯一的常驻位让给「预览」按钮——阅读与编辑之间的往返比导出高频。
- 命令面板的模式过滤：预览态 8 项（回到编辑 / 历史 / 字号 ± / 导出 ×4），编辑态 11 项，源码态 9 项；过滤规则即 `data-only` + 当前模式项自隐藏，分组无可见项时整组隐藏。

## 6 · 已实现的交互（原型）

- 模式切换（编辑 / 源码 / 预览）、预览态收缩为「预览中 / 历史 / 导出 / 编辑」。
- 专注态：侧栏退场 + 可见退出入口（A 右上胶囊；B/C 右下 HUD）。
- 工具条开关：A 折叠为顶部把手；B 胶囊收缩；C 细线切换 + 左上角「格式 ⌘/」。
- 字号 13–26 实时改变正文，四档预设 + 重置，面板显示当前值。
- 导出四格式：点选后 toast 反馈「已开始导出…」。
- 历史记录弹窗；保存的 已保存 / 未保存 / 保存中 三态；正文可直接输入触发未保存。
- 快捷键：⌘S 保存、⌘/ 工具条、⌘K 命令面板（C）。

## 7 · 风险与实现提示

1. **宽度**：1440 且大纲展开时主区约 884px。A 已加 ≤1240px 降级（收起目录路径、「导出」只留图标）。落地时建议再加一档：把「专注」收进溢出。
2. **浮层遮挡**：B 的胶囊 sticky 在正文上方，首行需 92px 顶距（已实现），滚动时注意与页内查找高亮、块菜单的 z-index 关系。
3. **导出入口**：C 版没有顶栏导出，鼠标用户需 ⌘K → 导出 HTML 两步；若担心被埋，在「···」里补一条兜底即可，不动顶栏结构。
4. **导出实现**：HTML/Markdown 由编辑器 markdown 直接生成；PDF 在端内直接生成——整篇渲染后按 A4 比例切页、每页内嵌 JPEG 写入 PDF（不弹打印框）；图片走同一个渲染器，按笔记服务器地址内联，失败要有错误提示而不是静默。
5. **字号持久化**：按笔记还是全局？原型按"记在本机、下次沿用"处理，落地前需确认是否跟随账号同步。
6. **保存按钮形态**：C 把状态并进按钮；若后端保存是显式动作且失败要留在编辑态，合并形态需要"保存中/失败"两套文案。
