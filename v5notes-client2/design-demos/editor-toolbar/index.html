还有两种排法

现在的编辑态顶栏把模式、预览、专注、历史、保存挤在同一排，字号、导出、工具条开关还没有位置。这一轮先不写组件，先给三种结构：它们的差别不是换个皮，而是「谁该一直露面、谁该等你去叫」。

六格候选

三套逻辑各出两个 · 深色框为出完整版的方向

每条逻辑先问一个不同的问题：A 问「十个按钮怎么排得下」，B 问「哪些动作属于文档、哪些属于排版」，C 问「写的时候到底需要看见什么」。两个候选分别代表同一问题下的松 / 紧两种回答。

A · 三段式单行

一条 52px 的顶栏，从左到右读作「这是哪篇 → 怎么看 → 怎么交出去」。

结构
左侧身份簇：折叠栏、目录/标题、保存状态；右侧三簇用 1px 竖线隔开：视图（专注、字号、历史）· 模式（所见即所得 / 源码 + 预览眼睛）· 交付（导出、保存、大纲）。
工具条开关
折叠钮长在格式条自己的右端，指向它要收起来的东西；收起后正文顶部留一条 22px 的浅色把手，随时点回来。
好处
所有动作一次可见，迁移成本最低；现有保存分裂菜单、大纲开关、面包屑全部保住。
代价
1440 下刚好，大纲展开或窗口变窄需要降级（已做 ≤1240px 收起目录与「导出」文字）。仍是「工具栏思维」，写作时存在感最强。

B · 悬浮机具

把「改文件」和「改字」拆开：文件的事留在顶栏，字的事漂在正文上方。

结构
顶栏只做文档级动作：标题、保存状态、专注、历史、工具条开关、导出、保存、大纲。模式切换、格式按钮、字号、预览收进一条 42px 悬浮胶囊，居中漂在正文列上方，滚动时吸顶。
工具条开关
开关在顶栏（常驻、有 aria-pressed），按下去胶囊只收起排版键，模式与字号留下——隐藏不等于失去入口。
好处
省掉一整条 44px 的灰带，正文更靠上；排版键永远在手指附近，视线不用回到顶栏；专注态真正只剩字。
代价
胶囊会压在正文上方，首行需要让位（已留 92px 顶距）；浮层在低分辨率下要防止与滚动条打架。

C · 极简写作条 + 命令面板

默认状态下顶栏只有四件事：命令、预览、保存、大纲。

结构
顶栏 46px：折叠栏、标题、⌘K 命令、预览、合并了状态的保存按钮（干净时直接写「已保存」，脏了才变成「保存」）、···、大纲。格式条降为一条无灰底的细线，贴着正文左缘。导出整条从顶栏撤掉，交给命令面板——把仅剩的一个常驻位让给「从阅读回到编辑」这条更高频的往返。
工具条开关
格式条右端「隐藏」；隐藏后正文左上角留一个低对比的「格式 ⌘/」，⌘K 里也能一键切回。
模式感知
命令面板按当前模式过滤：预览态只剩「回到编辑 / 历史 / 字号 / 导出」（8 项），编辑态 11 项，源码态 9 项；面板顶部写明「当前 · 预览 · 只读」，底部标明「只列出当前模式可用的命令」，分组标题在整组不可用时自动隐藏。
好处
视觉噪音最低；所有功能在一个可搜索的列表里，快捷键、当前状态、说明都写在同一行；新增功能不用再抢顶栏位置，也不会在错误的模式里出现。
代价
导出现在只能从 ⌘K 进（鼠标用户两步：⌘K → 导出 HTML）；命令面板需要做键盘可达、分组、按模式过滤、当前态标注，实现成本最高。若日后发现导出被埋，回退方案是在「···」里补一条兜底，不必动顶栏。

我的建议

如果这一轮要的是「把新功能塞进去、别让老用户迷路」，选 A：它只是把现有一排重新分组，字号、导出、工具条开关都有了明确的家，改动最小、验收最快。

如果目标是「让编辑页更像一个写作工具」，选 B：它真正解决了「格式条占掉 44px、正文往下掉」的问题，而且隐藏工具条时模式切换不消失——这是三版里唯一把「隐藏」设计干净的一版，也是我个人最想落的一版。

C 更像一次产品表态：把工具栏从「排布问题」变成「检索问题」。它最适合后续功能还会继续长的阶段，但需要额外的命令面板、快捷键体系和一次用户教育。

  1. 你选一个方向（也可以指定「A 的结构 + B 的胶囊位置」这类组合）。
  2. 我按选定的方向落到 EditorPane.vue + style.css，复用现有的保存分裂菜单、大纲开关、专注态与预览态规则。
  3. 导出四项和字号持久化需要真实实现（HTML/Markdown 可直接生成、PDF 走打印样式、图片走整篇渲染），我会同时给出实现路径与降级方案。

验收时要盯的几件事

  • 1440 且大纲展开时（主区 ≈884px）顶栏不换行、不截断保存按钮。
  • 预览态只留「预览中 / 历史 / 导出 / 编辑」，符合现有模式契约。
  • 专注态必须有可见的退出入口，且目录可恢复。
  • 工具条隐藏后仍能一键找回（把手 / 顶栏开关 / ⌘/ 三条路至少留两条）。
  • 导出前自动保存，失败时不关闭菜单并给出行内错误。

原型为静态 HTML + 原生 JS，仅用于布局评审；所有截图由 Chrome 在 1440×900 下渲染（2× 像素密度）。
