# 服务器设置 · 三个方向

> 交付物：`prototype.html`（六个初稿可切换：`?v=1a…3b&state=official|custom`）、`login.html`、`shots/directions.png`
> 六个初稿见 `shots/contact-sheet.png`；挑出的三个方向见 `shots/directions.png`

## 共同约束（所有方向一致）

- 设置弹窗新增「服务器」区，包含：服务器地址输入框、「使用官方地址」复选框、保存按钮、行内校验与"保存后需重新登录"提示。
- 勾选「使用官方地址」→ 地址框 disabled、保存按钮 disabled（无改动）；官方 URL 只在代码常量里，页面只显示"官方服务器"。
- 登录页不再有服务器地址输入框：改成一行"服务器 · 官方服务器 / 自定义地址"状态，右侧「更改」打开设置。
- 保存后若地址变化 → 清 token（有草稿先确认），回登录页。

## 方向 1b · 顶部连接卡

把"连接"提到弹窗最上方做成一张浅绿卡片：状态点 + "连接 + 官方服务器"，卡片内一行放地址输入、复选框、保存。
- 优点：连接是所有数据的前提，放最上面符合心智；卡片和下面的偏好行分成两个层次。
- 代价：比现有设置多一层容器；卡片内元素较多，窄窗口（<700px）需要折行。

## 方向 2b · 两行表单

沿用现在设置弹窗的行节奏，但把服务器做成一个小表单块：标签"服务器地址"、输入框 + 保存、下一行复选框 + 说明。
- 优点：最贴近现有设计语言，改动最小；表单语义清楚，和"通用 / 工作区"同构。
- 代价：和偏好开关行看起来不太一样，需要在视觉上接受"这里是个表单"。

## 方向 3a · 凭据条

把服务器当成一张"凭据"：锁图标 + "官方服务器 · v5ai" + 右侧「官方 / 自定义」胶囊；取消勾选后凭据条原地变成输入框。
- 优点：状态最直观，官方地址不可见这一约束在视觉上成立（只显示托管方）；自定义时又直接可编辑。
- 代价：比另外两个方向多一个"胶囊"，和现有极简风略重。

## 登录页（三个方向共用）

- 原"服务器地址"输入框删除，换成一行：`● 服务器 · 官方服务器   更改`（自定义时显示地址，点右侧圆点变琥珀色）。
- 「更改」和右上齿轮都打开设置弹窗；登录页不再出现官方 URL。
- 见 `shots/directions.png` 最后一行。

## 操作步骤（保存设计）

1. 启动：若从未保存过服务器，默认勾选「使用官方地址」，使用代码常量。
2. 登录页右上齿轮（或状态行「更改」）→ 设置弹窗。
3. 服务器区显示当前状态：勾选时地址框禁用，文案"官方服务器 · 不可编辑"。
4. 取消勾选 → 地址框可编辑，预填上次保存的自定义地址（空则占位 `https://notes.example.com`）。
5. 输入地址：失焦或点保存时校验——必须是 http/https、自动去掉末尾斜杠；非法则行内红字、保存禁用。
6. 点保存：
   - 未登录：写入 localStorage，设置内提示"已保存"。
   - 已登录且地址变化：应用内确认框"更改服务器后需要重新登录"→ 确认后清 token（有草稿先确认清除）→ 回登录页。
7. 回登录页：服务器行显示新状态，输入用户名密码登录；登录成功再写一次 `v5notes-server`。
8. 再次打开设置：勾选状态与地址一致；勾选官方时地址不可编辑。

## 实现落点（选定方向后）

- 新增 `src/models/serverSettings.ts`：`OFFICIAL_SERVER`、`normalizeServer()`、读写 `v5notes-server`、官方标记 `v5notes-server-official`。
- `SettingsDialog.vue`：增加 `server`、`useOfficial` props 与 `save-server` emit（或 v-model），新增服务器区。
- `LoginView.vue`：删除服务器输入框，改状态行 + `emit('settings')`。
- `useWorkspace.ts`：`saveServer()`（校验、持久化、地址变化时清 token/草稿并回登录）；登录页不再依赖 server 输入。
- 单测：`normalizeServer` 校验、切换服务器后的状态清理。
