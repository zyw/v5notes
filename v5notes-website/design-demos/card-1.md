# 方向卡 1 · 白（原研哉 / Kenya Hara）

读 spec.md 拿全站文案与素材。本卡只管「长什么样」。

## 一句话
一个几乎全空的纸面网站：一句大字、一张图版、一条发丝线；让产品截图像书里的图版一样被安静地摆着。

## 令牌
- 纸 paper #fbf9f3；更深一档 canvas #f4f1e8；纯白只用于图版内衬 #fffefa
- 墨 ink #26332c；次级 #40514a；次要 #6b7b70；极弱 #8a958c（仅图注）
- 发丝线 #e3e0d6；强调墨绿 #315b4a；青瓷 #2fa9a4（全页 ≤3 处，只做小点/短线）
- 字体：标题 'Songti SC','Noto Serif SC',serif；正文 'PingFang SC','Hiragino Sans GB','Noto Sans SC',sans-serif；图注/元数据 'SF Mono',ui-monospace,Menlo,monospace
- 字号：H1 68px/1.22 字距 .01em；section 标题 42px/1.35；导语 20px/1.95；正文 17px/1.9；图注 13px；小标签 12px，字距 .08em（只在图注/元数据用，不要每个标题都加）
- 版心：页面 max-width 1120px；正文栏 640px；1440 时左右留 160px；区块上下 padding 150–210px

## 版式
1. **导航**：高 92px，左图标＋V5Notes（PingFang 17px），中间 5 个锚点（15px），右「下载桌面端」墨绿描边胶囊（不是实心）。底部 1px 发丝线。
2. **首屏**（min-height 760px，不用 100vh）：左上 H1 占 8 列；H1 下 32px 一句副标（宽 520px）；再下 40px 两个按钮（实心墨绿＋文字链接）。右下方 620px 宽的图版（client-home.jpg），外边 1px 发丝线 + 8px 白边；图版左下方一行 13px 图注「图版 01 · 客户端的空白页」。首屏右侧与下方留大片空。
3. **第 1 段（为什么）**：section 标题左对齐占 6 列；导语右移对齐到第 8 列（形成错位）。四组对照做成两列：左列「原来的麻烦」用 #8a958c，右列「V5Notes 的做法」用墨；两组之间 1px 竖发丝线；每行 28px 上下留白。
4. **第 2 段（写作）**：标题 + 导语；下面 6 条做成「定义列表」两列（每列 3 条），条目标题 19px 宋体，说明 16px，条目之间只用 1px 横线。右侧放一张窄的 client-source.jpg 图版（宽 420px），图注「图版 02 · 源码模式」。
5. **第 3 段（回退）**：整幅图版 client-history.jpg（宽 980px 居中），图注；图版下 3 条横排（每列 300px），标题 19px + 说明 16px。
6. **第 4 段（管理）**：admin-home.jpg 图版（宽 980px）；6 格用 2 列 × 3 行，每格只有标题 + 一句，无卡片无边框，靠 1px 分隔线。
7. **第 5 段（三端）**：一条横向的 1px 线，线上三个节点（客户端 / API / 管理后台），节点只用文字＋小圆点，不画复杂 SVG。下面一行元数据（MySQL / Redis / Flyway）。
8. **第 6 段（部署）**：代码块用 mono 14px，纸色底、1px 框、内 padding 24px；代码块右侧竖排说明三种方式；备份三个目录用定义列表；第一次打开用 3 行小字。
9. **第 7 段（技术栈/开源）**：左栏技术表（两列，1px 横线），右栏 3 条说明。
10. **CTA**：居中，宋体 52px 一句话，两个按钮。
11. **页脚**：1px 线，三栏小字；含图标、许可、版本。

## 动效
- 一次编排的入场：H1、副标、按钮、图版依次上移 12px + 淡入，总时长 900ms，缓动 cubic-bezier(.2,.7,.2,1)。其余不做滚动动画。
- 链接 hover：下划线从 0 到 100% 宽（180ms）；按钮 hover：底色加深一档。
- prefers-reduced-motion 时全部静止。

## 禁止
- 不要渐变、不要卡片阴影、不要圆角过大（图版 4px，按钮 999px）。
- 不要把首屏填满；不要把截图放大到全宽当 hero。
- 不要用「01/02/03」编号（图版编号 01 可以，因为图版是序列）。
