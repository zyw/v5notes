# 新增：核心编辑器 v5md（三版共用内容）

v5md 是 V5Notes 的**核心编辑器**，开源（MIT）。官网必须把它当作核心功能单独讲一节，不能只当技术栈里的一行。

## 事实（已核实，只能用这些）
- 仓库：https://github.com/zyw/v5md ｜ 主页：https://v5md.v5ai.xin ｜ 许可：MIT ｜ 当前版本 v0.0.3
- npm 包：@v5md/vue、@v5md/react、@v5md/view、@v5md/core、@v5md/plugin-typography、@v5md/plugin-export（六个包，ESM）
- 定位：所见即所得 Markdown 编辑器；Markdown 字符串是唯一数据源，没有私有 JSON / HTML 模型。
- 工作方式：输入 / 粘贴 / 工具条 / 快捷键 → 改 Markdown 字符串（带撤销历史）→ micromark / mdast 解析成带偏移的节点树 → 只重绘文档区并按偏移放回光标；选区用字符串偏移，不是 DOM Range。
- 六个卖点（逐字用）：
  1. 数据就是 Markdown — 拿到的不是私有 JSON 或 HTML，而是可以直接入库、走 diff、交给任何 Markdown 渲染器的字符串。
  2. 标记按需显形 — 平时看到的是排版结果；光标落在标题、粗体、代码块上，才露出 #、**、围栏，改完自动收回。
  3. 中文输入法友好 — 组合输入期间不重绘 DOM，候选框不错位，拼音上屏不丢字。
  4. 粘贴即转换 — 从网页、Word、飞书复制来的富文本，先转成 Markdown 再写入文档。
  5. 不锁死框架 — @v5md/vue 与 @v5md/react 只是薄壳，核心是 @v5md/view 的 Editor 类，也能挂到任意 DOM。
  6. 可插拔 — 工具条、命令、对外 API 都能由插件提供；字号和导出是官方插件。
- 支持内容（一行排完）：标题、粗体、斜体、下划线、删除线、高亮、行内代码、链接、列表、任务列表、引用、带语法高亮的代码块、表格、分割线、图片（可拖拽缩放）、KaTeX 公式、Mermaid 图表、YAML frontmatter；以及撤销重做、查找替换（正则 / 全词）、整篇源码模式、大纲跳转、表格行列编辑、导出 Markdown / HTML / PDF / 图片。
- V5Notes 客户端用 @v5md/vue 驱动正文编辑；v5md 也可以单独用在别的项目里。
- 不要写：编辑器有 AI 补全、实时协作、移动端 App —— 都没有。
