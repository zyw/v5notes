# spec.md · V5Notes2 后台「总体 loading」重设计

> 本文件只写**要说什么**，不写长什么样（长什么样是 direction 卡的事）。三版共用本 spec。

## 1 · 这是什么

v5notes-admin2（Vue 3 + Element Plus）的**加载体验系统**重设计。不是「把转圈换个颜色」，是把用户等待产品的那几秒当作一个界面来设计。

## 2 · 受众与场景

| 场景 | 谁 | 心理状态 | 停留时长 |
|---|---|---|---|
| 冷启动 / 刷新 | 全部管理员 | 「是不是卡死了？」 | 0.5–6s（取决于 bundle 下载） |
| 侧栏切页 | 运营、内容编辑 | 「点到了吗？」 | 150–900ms |
| 表格/详情取数 | 运营、运维 | 「在等数据，先别动」 | 200–1500ms |
| 慢网 / 后端超时 | 任何人 | 「要不要重试？」 | 5s+，可能失败 |

## 3 · 要解决的六个问题（按优先级）

1. **身份断裂**：启动屏是紫色，进去是薄荷绿。第一秒就在撒谎。
2. **假等待**：三层圆环转圈 = 无信息。用户不知道在等什么、还要多久、能不能取消。
3. **没有兜底**：bundle 拉失败 / 后端 502 时，页面永远停在转圈，没有重试按钮、没有错误说明。
4. **布局跳变**：表格从「白卡+转圈」跳到「10 行数据」，行高从 0 变 54，整页抖一下。
5. **转场生硬**：NProgress 蓝条 + 整页白闪 + 内容无淡入。
6. **层级不分**：冷启动、路由切换、局部取数、按钮提交全用同一个视觉音量，用户分不清「等整个系统」和「等一个按钮」。

## 4 · 要交付的加载面（每一面都要有明确视觉音量）

| # | 面 | 视觉音量 | 必须做到 |
|---|---|---|---|
| L0 | 启动屏（首屏 HTML 内联） | 最强，唯一一次全屏 | 品牌色 + 真实阶段 + 耗时读数 + 8s 超时兜底 |
| L1 | 路由切换 | 中 | 2px 品牌色进度条，不遮内容，不闪白 |
| L2 | 页面骨架 | 中 | 骨架形状 = 真实布局的格子，不是灰条堆 |
| L3 | 局部取数（表格刷新/详情） | 弱 | 只遮该区域，保留表头与分页，不糊整张卡 |
| L4 | 按钮提交 | 最弱 | 按钮不变宽，转圈在图标位 |
| L5 | 失败 / 超时 | 特殊 | 说清原因、给重试、保留已加载部分 |

## 5 · 内容（真实文案，不用 Lorem）

- 品牌：V5Notes2 · 云笔记 · 管理控制台
- 冷启动阶段（**真实事件驱动，不是装饰**）：
  1. 解析页面骨架（HTML parsed）
  2. 载入应用脚本（module loaded）
  3. 校验会话（getInfo）
  4. 生成菜单与路由（generateRoutes）
  5. 渲染工作台（首屏 paint）
- 耗时读数：`已用 1.8s` / 慢网提示 `网络似乎较慢，仍在重试…`
- 超时兜底：`加载时间超出预期` + `重新加载` / `查看网络诊断`
- 路由切换：不写文案，只有进度条 + 目标页标题（`成员管理`）
- 骨架：无文案（形状即信息）
- 表格局部：`正在刷新成员列表…` + 保留表头
- 失败：`会话已过期，请重新登录` / `服务暂时不可用（502）` + 重试

## 6 · 情感基调

**克制的确定感**：等待时用户唯一需要的是「它在动、它在哪一步、还差多久、不行我能做什么」。任何让用户觉得「这网站很酷」的努力，都要让位给这四件事。

## 7 · 输出格式与尺寸（三版必须统一）

- 单文件 HTML，1440×1024 舞台，深/浅两态同页可切（右上角开关）
- 顶部一条**状态切换条**：启动 / 路由 / 骨架 / 局部 / 失败（可点，真的切换）
- 默认进入「启动」态并自动播放一次；带「重播」按钮
- 控制台零报错；正文 ≥14px、标签 ≥12px；正文对比度 ≥4.5:1
- 图片与 logo base64 内嵌
- 截图：每版至少 启动态 + 骨架态 两张

## 8 · 已知约束

- 落地目标：Vue 3 + Element Plus 2.14 + SCSS 令牌（`--app-*`）；启动屏必须留在 `index.html` 内联（此时还没有 JS）
- 不得引入新字体文件（沿用 PingFang SC / MiSans 系统栈 + 已有等宽栈）
- 不得引入动画库；纯 CSS + 少量原生 JS
- 保留已批准的薄荷工作台令牌，不新增色相
- 深色主题也要成立（`_theme-dark.scss` 已存在）

## 9 · 三版怎么读

三版共用本 spec 与同一份品牌令牌，差异在**骨架与节奏**，不在配色。
