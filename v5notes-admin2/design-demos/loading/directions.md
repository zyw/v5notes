# directions.md · V5Notes2 加载体验 —— 六个方向

> spec 只规定了「要说什么」，方向卡规定「看起来长什么样」。每版开工前只读 spec + 自己这张卡 + 品牌令牌，不参考其它卡。

---

## 方向 A1 · 现实的预防者 —— 同步进度舱
**逻辑与来源**：最佳设计师｜线性团队的产品设计直觉（已亲眼核看 linear.app）。做桌面效率软件 loading 做得最舒服的，是把「等待」设计成「这锅数据正准备上桌」的厨房。这里不模仿它的项目气质，借的是它对进度的处理：**进度是真实的、逐段的、可读的**。
**借的是什么**：
- 单先生命：一个环 + 一段文字 + 一个耗时数，不再有什么都转
- 阶段是「列表行进」而非「圆周旋转」——每完成一件，点亮一格（check），当前件用薄荷高光外描边呼吸
- 精确时值：`已用 2.4s` 走等宽数字，右下角不打扰
- 深色底承接已批准抽屉头 `#0f3d33→#1c5a48` 渐变，浅色态为 `#f4f7f5` 画布
- 超时 8s：进度环变琥珀 `#d9a33b`，多一行 `加载时间超出预期` + 重试；失败态砖红一次
**主角素材**：程序化 —— 真实 CSS 进度环 + 五阶段行军清单（无图，纯排版）
**骨架**：居中一列 —— logo（顶部）→ 环 → 当前阶段 → 已完成清单 → 耗时
**胆量花在**：把「冷启动是不是卡死」这个问题，用一个**会动会读秒的真实进度**正面解决
**form 来自内容的哪里**：这个产品真的在干 5 件事（parse bundle → user → routes → render），清单不是装饰，租金来自产品自己

## 方向 A2 · 守序的园丁 —— 薄荷时钟
**逻辑与来源**：最佳设计师｜原研哉的「把等待变成被尊重的时间」的克制哲学延伸（非模仿具体作品）。把一个本会被无视的启动时间，变成一次有呼吸的视觉停顿。
**借的是什么**：极端留白、素材本人做主角、极少的字。这里的主角是一个**呼吸的薄荷圆点**（2s 周期，径向呼吸），旁边只放两个字级：大号 stage 词 + 等宽耗时。
**主角素材**：程序化 —— 单个呼吸圆点 + 极简字级
**骨架**：居中一枚呼吸点，上方 V5Notes2（可小 logo），下方当前阶段大字 + 耗时小字
**胆量花在**：把 loading 做到「几乎什么都没有」——测试用户敢不敢让它就这么安静地等
**form 来自内容的哪里**：后台本来就是安静的地方，加载不该比里面的内容更吵
> 注：A2 与 A1 同根（都是「真实进度 + 精确读秒」），但 A1 是「清单行进」，A2 是「单点呼吸」，骨架差异足够；若两者皆被比「换皮」，保留 A1，A2 降级为备选。

## 方向 B1 · 现实的预防者 —— 梅花的重量
**逻辑与来源**：现实参照｜Linear / Vercel / Stripe 的 loader 家族（同媒介：都要抢「这么重的后端在启动」）。借的是真实产品把「重启动」做轻的手感：进度条不是靠转，是靠 **% 打底 + 顶部细条 + 内容骨架占位**。
**借的是什么**：
- 顶部 2px 薄荷进度条（替代 NProgress 蓝条），路由切换时也用（L1）
- 「先画骨架，再长内容」：启动后立刻显**结构骨架**（侧栏行、指标卡、表头、表格行）而非空屏——**形狀即信息，0% 时就有布局**
- 阶段小字只在最底部一行，不抢戏
**主角素材**：程序化 skeleton（表格/侧栏/卡片灰块，薄荷微光扫过）
**骨架**：真实 admin 布局的透视骨架（侧栏 + 顶栏 + 指标 + 表），顶部进度条覆盖
**胆量花在**：进度不是「转」，是「先给你一个会长的骨架」——内容加载和布局加载同步发生
**form 来自内容的哪里**：后台是表格的世界，加载就该先给你表格的形状

## 方向 B2 · 守序的园丁 —— 会失效的安全网
**逻辑与来源**：现实参照｜Stripe 的 Dashboard 错误与重试处理（已核看）。借的是真正的退路设计：加载环节**必然涉及失败**，好的 loader 不是一直转，而是在坏的时候说人话。
**借的是什么**：
- 「启动进度」之外，同页演示**三、四个失败剧本**（超时 / 会话过期 / 502 / 断网），每个都有原因 + 可点按钮
- 转圈永远可被打断（取消 / 重试），不让人干瞪眼
- 局部失败保留已加载内容，只缺口区域
**主角素材**：程序化 —— 状态卡（error / empty / timeout）+ 动作按钮
**骨架**：与 B1 同系（XXX），但在进度条 + 骨架之外，多一整套失败态
> 注：B2 与 B1 同属「现实参照」，骨架几乎同一套（进度条 + 骨架），本质是同一张骨架的「正常 + 失败」两态。若两者都入选会撞。**B1 更像三方向，B2 更像 B1 的一格**。三版里**不**同时选 B1+B2；除非骨架大幅分化（B1 做浅色表格骨架，B2 做深色状态舱），否则 B2 作为备选展示。

## 方向 C1 · 秒数轮盘 —— 会呼吸的墨
**抽到**：秒数 24 → east 区 **11 佐藤可士和　极简符号**（纯色满铺一个字/标志 + 一半白信息区 + 最多三色）+ **TODO 标本名字**。
**借的是什么**（<70% 还原，标注降级项）：
- **一个字/一枚标志占一半画面**——把「V5Notes2」的 logo 或「等」字放大到占左半屏，右半屏才是进度信息（纯色块 + 白信息，三色内：薄荷/琥珀/墨）
- 满铺色块底（深墨绿） + 反白巨字 + 一行信息区
- **降级**：原作是「佐藤可士和」，灵魂在「红方块 + 白粗字 + 片假名」的单色满铺占位；这里用已批准薄荷墨绿 `#1c5a48`（或深 `#0f3d33`）——品牌色，不搬日章旗红
**主角素材**：巨字「等」或 logo（字是主角，纯排版）
**骨架**：左右对开 —— 左：整块薄荷满铺 + 巨大「等」/ logo；右：白底信息区（产品名 + 阶段 + 耗时 + 重试）
**胆量花在**：把 loading 做成一个「海报时刻」——不是界面，是一张招贴
**form 来自内容的哪里**：admin 后台也需要一个「品牌该有的样子」的瞬间，这个瞬间只在启动时才有

## 方向 C2 · 秒数轮盘 —— 行动的静物
**抽到**：秒数 TODO → web 区 **13 Glassmorphism Bento（Linear 暗色发光 + Bento 网格）**。
**借的是什么**（还原 70%，标注降级）：
- 深底 + 品牌绿光晕（中央一个薄荷 radial 光晕，替代紫/蓝）
- Bento 网格承载骨架：进度条 / 阶段格 / 指标格 / 迷你状态格，拼成一个「加载仪表盘」而非空屏
- **降级**：原作深黑底 + 蓝紫光晕；这里用深墨绿底 + 薄荷光晕（品牌色），玻璃拟态的 blur 保留
**主角素材**：程序化 Bento 面板 + CSS 光晕
**骨架**：居中一块 Bento 面板（2×2 / 3×2 格），每格一个加载切片，顶部细进度条
**胆量花在**：把「在等」做成「在看一张会自己长出来的仪表盘」——等待本身变成内容
**form 来自内容的哪里**：这道后台有价值的东西就是「数据与指标」，加载期预告它

- 状态机：`booting → routing → skele → partial → (timeout|fail)`
