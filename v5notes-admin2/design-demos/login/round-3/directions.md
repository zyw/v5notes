# 登录页 · 第三轮六个候选 → 三个正式稿

前两轮（../dir-1..3、../round-2/dir-4..6）已试过：居中单卡、左右双栏＋产品插画、几何主图、横向表单、深绿单卡、书页侧注。共同问题是三张都会滑回「居中白卡」，或靠装饰插画撑画面。第三轮换判断标准：**登录页应该像这套管理端自己的一页**，结构差异放在版式上，不放在配色和插画上。

## 六个候选

### A1 · 门廊 Shell Echo —— 正式稿 dir-1
- 逻辑与来源：最佳设计师思维探索。借用的是**这套系统自己的页面机制**（已批准 `../admin-redesign/dir-2.png`：白侧栏 + `#f4f7f5` 画布 + 页头 + 白卡），不借外部落地页。
- 借的是什么：264px 白色品牌轨 + 发丝线；把「页头（眉标 + 标题 + 一行说明）」原样搬进登录页；表单作为画布上的一张白卡，宽度克制。
- 主角素材：品牌轨本身（真实 Logo + 产品名 + 版本号 + 语言切换），以及表单这一张卡。
- 骨架：左白色品牌轨 264px（Logo / 产品名 / 版本 / 语言 / 版权）＋ 右 `#f4f7f5` 画布（页头 + 表单卡 460–560 宽）。
- 胆量花在哪：去掉所有营销内容，让登录页就是后台的一页——左边是应用的侧栏，右边是页面。
- form 来自内容的哪里：管理员登录后进入的正是这套壳，入口先给出同一套壳。
- 手机：品牌轨收成 64px 顶栏（Logo + 产品名 + 语言），表单整宽。

### A2 · 顶栏 + 双列表单 —— 备选
- 逻辑与来源：最佳设计师思维探索 · 横向网格。
- 借的是什么：把必填项按两列排，主操作落在第二列末。
- 骨架：顶部品牌栏 + 双列表单卡。
- 胆量：表单字段两列。
- form：管理端登录字段固定三个，两列能压缩高度。
- 淘汰原因：横排表单在第二轮 dir-4 已经失败（对齐散），本轮不再做。

### B1 · 深色封面 Cover —— 正式稿 dir-2
- 逻辑与来源：现实参照 · 现有登录页 `../admin-redesign/implemented-login.png`（深绿底 + 白表单）。保留这层品牌关系，但去掉装饰指标卡与紫色渐变，改成整栏白面。
- 借的是什么：深绿大色场与白色栏的对切；左侧大字承担品牌，右侧白栏承担表单；底部 mono 版本 / 版权带。
- 主角素材：74–84px 的中文大字标题 + 真实橙色图标。
- 骨架：左侧 56% 深绿（Logo、大字标题、一句说明、底部元信息）｜右侧 44% 白色整高纵向表单栏（无卡片、无圆角、无阴影）。
- 胆量花在哪：深绿占半屏，白栏一刀切，不用卡片悬浮。
- form 来自内容的哪里：重新登录是一个「切换」动作，深色包裹告诉人这是入口而不是工作台内部。
- 手机：深绿收缩成 220px 顶部带，白栏接管整屏。

### B2 · 侧轨 + 居中表单 —— 备选
- 逻辑与来源：现实参照 · 现有工作台的窄导航轨。
- 借的是什么：窄侧轨 + 页面中心表单。
- 骨架：56px 侧轨 + 居中表单。
- 胆量：导航压成一条品牌轨。
- form：登录后进入的是后台导航。
- 淘汰原因：与 A1 同为「左轨」骨架，会撞。

### C1 · 台账 Ledger —— 正式稿 dir-3
- 逻辑与来源：秒数轮盘 · 东亚风格「书籍设计 / 版心与栏线」，样张 `/Users/jingyuan-mb01/.agents/skills/huashu-design/assets/style-specimens/east/01-lu-jingren-bookcraft.jpg`（已亲眼看过）。只在「版心、行与线」上借，不做书封、不做竖排、不加纸纹。
- 借的是什么：不居中的版心；行与行之间 1px 细线；标签在左、字段在右的台账行距；右下角压一块 mono 元信息稳定构图。
- 主角素材：表单本身——没有卡、没有阴影，靠行距和线立起来；按钮窄且靠右。
- 骨架：整页纯白（`#ffffff`），顶部 60px 工具条（Logo + 产品名 · 语言）；正文版心自左 128px 起、宽 520px 的行式表单；右下角固定 mono 元信息块（产品 / 版本 / 版权）；字段输入只有底部 1px 线。
- 胆量花在哪：整个登录表单没有任何容器，全靠版心、行线与留白；页面右侧大面积空白是构图，不是缺失。
- form 来自内容的哪里：管理端的所有信息都以行与列呈现（表格、表单页），登录字段也按行读。
- 手机：版心收进 20px，标签移到字段上方，右下元信息块并入页脚。

### C2 · 巨字封面 —— 备选
- 逻辑与来源：秒数轮盘 · 网页风格 Editorial Brutalism 样张。
- 借的是什么：巨大汉字与规则线。
- 骨架：左侧巨字 + 右侧紧凑表单。
- 胆量：标题即版面。
- form：登录是单一动作。
- 淘汰原因：巨字会把这套克制的管理端拉成海报，和「现有页面风格」相冲。

## 结论
三张正式稿：`dir-1.html`（门廊）、`dir-2.html`（深色封面）、`dir-3.html`（台账）。
备选 A2 / B2 / C2 不进完整版，方向卡留档。
