# V5Notes2 登录页 · 第三轮共用 Spec

继承 ../spec.md 与 ../brand-spec.md。第三轮目标：在已批准的「方向 2 · 薄荷工作台」视觉系统内，为登录页找到**结构上真正不同的三种写法**，让用户选一种落地到 `src/views/login.vue`。

## 产品与场景
- 产品：V5Notes2 云笔记 · 管理控制台（Vue3 + Element Plus 管理端，已上线）。
- 用户：每天使用管理端的团队管理员与运营人员。
- 场景：打开管理端，或会话失效后重新登录。他们要的是「快速认出来 + 快速进去」，不是了解产品功能。
- 页面语气：清楚、安静、可信。与工作台、成员管理、笔记管理等既有页面**同一套系统**，不是营销落地页。

## 内容（三版完全一致，只比较结构）
- 品牌：真实 Logo PNG（橙色渐变），产品名「V5Notes2」，副名「云笔记 · 管理控制台」。
- 表单标题：`欢迎回来`（英文 `Welcome back`）；说明一行：`使用管理员账号进入工作台。`（英文 `Sign in with your administrator account.`）。
- 字段：账号 / 密码 / 验证码（图片码）。三者都可能必填，验证码按现有后端开关。
- 选项：记住账号。
- 主按钮：登录（英文 Sign in）。
- 第三方入口：微信、MaxKey、TopIAM、Gitee、GitHub（现有后端支持的五个，不多不少）。
- 语言切换：简体中文 / English，页面所有文案真实切换（不是只换按钮文字）。
- 页脚：`Copyright © 2018-2026 疯狂的狮子Li All Rights Reserved.`；可另加真实版本号 `v6.1.0`（来自 package.json）。
- 不新增：注册链接、忘记密码、邮箱 / 手机 / Passkey 登录、任何营销指标或用户评价。

## 输出与尺寸
- 三个自包含 HTML（内联 CSS/JS，Logo 以 data URI 内嵌），桌面 1440×900 与手机 375×812 都要成立（同一文件响应式）。
- 三版结构不同（不是换色）：一个偏「应用内的页面」、一个偏「深色入口」、一个偏「文档 / 台账」。
- 只用 HTML/CSS/原生 JS，不引外部字体、CDN、图片。

## 交互（必须可点，纯前端静态展示）
1. 密码显隐切换（图标切换，aria-label 同步）。
2. 验证码点击刷新：换一组新字符（原型内生成 SVG 码图即可）。
3. 语言切换：中英文全部文案真实切换，含 title / placeholder / 按钮 / 页脚。
4. 空值提交：字段下方 inline 错误（不是 alert），第一个错误字段聚焦；错误出现不破坏布局跳动过大。
5. 提交加载：按钮进入 loading 900ms，然后显示「正在进入工作台…」，不发起真实请求。
6. 第三方入口：点击后在该区域给出 inline 提示（例如「将跳转微信授权」），不跳转。
7. 记住账号可勾选；刷新页面不需要保留状态，但勾选样式要按系统样式做。

## 视觉令牌（来自 src/assets/styles/tokens/_theme.scss，必须照用）
- 画布 `#f4f7f5`，卡面 / 白面 `#ffffff`，发丝边框 `#e6ebe7`，更浅分隔线 `#edf1ee`。
- 主色 `#1c5a48`，深 `#0f3d33`，hover `#236a55`，浅底 `#e8f2ec`，浅底文字 `#17624a`。
- 标题 `#15241e`，正文 `#2b3a32`，次要 `#5f7067`。
- 语义：success `#2f9e6b`，warning `#d9a33b`，danger `#b4534b`。
- 圆角：base 12 / sm 8 / md 10 / lg 14；按钮 10，输入 10，小图标块 8/10。
- 阴影：sm `0 1px 2px rgba(20,40,30,.05)`，md `0 10px 26px rgba(20,40,30,.07)`。不要大投影。
- 字体：`MiSans, "HarmonyOS Sans SC", "PingFang SC", "Noto Sans SC", sans-serif`；等宽小标签用 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`，只用于真正的元信息（版本号、状态、栏目标签），全页不超过 3 处。
- 橙色只来自 Logo 图标本身，不扩展成第二个 UI 强调色。

## 既有页面的手感（对齐它，别自创）
- 页头：可有眉标 + 大标题 + 一行副标题；标题 26–32px，副标题 14px `#5f7067`。
- 白卡 + 1px 发丝线 + 圆角 12 + 极轻阴影。
- 控件高 44–46px；输入框白底、1px `#dfe5e1` 边框、圆角 10、focus 时主色描边 + 3px `rgba(28,90,72,.12)` 外环。
- 主按钮：`#1c5a48` 实底白字，hover `#236a55`，圆角 10，阴影 `0 8px 20px rgba(28,90,72,.18)`（轻）。
- 不出现蓝色、紫色渐变、emoji 图标、左彩条卡片、卡片堆叠的营销网格。

## 可读性底线（硬要求）
- 正文 ≥14px，标签 ≥12px；正文对比度 ≥4.5:1；控件高 ≥44px。
- 留白是构图；1440×900 一屏内完成，不出现滚动条（手机可滚动，但首屏要有完整表单意图）。

## 验收
- 桌面、手机各一张截图，用 Chrome headless 渲染后亲眼看。
- 三版并排看：骨架不同、气质不同、没有一版是「居中白卡」的重复。
- `design_lint.py check` 红灯必修。
