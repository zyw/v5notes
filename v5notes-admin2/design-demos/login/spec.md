# v5notes-admin2 登录页设计 · 共用 Spec

## 项目与目标
为 V5Notes2 云笔记管理控制台整理一张与已批准“薄荷工作台”一致的登录页。页面要让现有管理员快速识别产品、填写账号信息并继续进入工作台。

## 用户、场景与核心信息
- 用户：使用管理端的团队管理员与运营人员。
- 场景：打开管理端或会话失效后重新登录。
- 首屏交代：V5Notes2 云笔记管理控制台、登录表单、验证码、记住账号选项、已有第三方登录入口。

## 文案与字段
- 产品名：V5Notes2 云笔记 · 管理控制台
- 说明：登录 V5Notes2 云笔记管理控制台。
- 字段：账号、密码、验证码。
- 选项：记住账号。
- 可用的第三方入口：微信、MaxKey、TopIAM、Gitee、GitHub。
- 不新增注册链接、找回密码或邮箱 / Passkey 登录。
- 支持简体中文与英文的预览态切换。

## 输出格式
- 三个自包含 HTML；桌面 1440×900、手机 375×812。
- 三版字段、交互、文案相同，只比较版式与视觉表达。
- 页面交互可点：密码显隐、验证码刷新、语言切换、字段必填校验、记住账号和第三方入口状态反馈。
- 原型不会提交账号信息或连接后端；按钮只展示界面状态。

## 已知约束
- 核心色彩沿用 #f4f7f5 / #ffffff / #1c5a48 / #e8f2ec。
- 使用真实 Logo PNG；橙色不扩展成第二套 UI 强调色。
- 正文不小于 14px、标签不小于 12px，按钮与输入控件至少 44px 高。
- 不使用真实用户信息或伪造业务指标；背景装饰只使用目录、笔记等已确认的产品概念。
