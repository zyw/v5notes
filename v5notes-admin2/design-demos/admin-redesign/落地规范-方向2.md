## 三、组件级规则（照 dir-2.html）
- **侧栏**：白底、logo 用新橙色图标（28px 圆角图标）+ 名称；菜单激活 = 薄荷底 + 深绿字 + 左侧无需竖条（B1 是块状高亮）。
- **顶栏**：白底发丝线；搜索框白底圆角 8；右侧图标 hover 薄荷浅底。
- **页头**：一行 —— 眉标(可选) + 大标题 + 副标题；右侧主操作「+ 新增成员」。
- **指标**：4 个扁平白卡（不是深色带），数字深墨绿、单位小字、左侧小圆点状态。
- **表格**：白卡内，勾选列 + 成员/部门/角色/状态/最后活跃/加入时间/操作；表头浅灰；行 hover 薄荷极浅；状态 pill 三色；操作图标低调。
- **分页**：当前页薄荷墨绿实底白字。
- **字体**：MiSans / HarmonyOS Sans SC / PingFang SC（现有），不引额外字体。

## 四、验收
1. `pnpm build`（或 `pnpm dev`）通过，无 SCSS 报错。
2. 登录页 + 用户管理页截图（1440 宽）与 `dir-2.png` 气质一致：薄荷单点、白卡、密度表、三色状态。
3. 浅/暗两态都验：切暗色后仍为「深绿墨色 + 薄荷强调」，不出现默认蓝。
4. 可读性底线：正文 ≥14px、标签 ≥12px、正文对比度 ≥4.5:1。

## 五、实施记录（2026-11-06，已落地真实代码）
