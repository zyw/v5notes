# V5Notes2 管理端整体重设计 · 六方向候选

> 共同输入见 spec.md / content.md。三套逻辑各出两个候选；秒数轮盘取 S=50：
> 网页分区 50%20+1=**11（暗色双色侧栏开发者作品集 Dark Editorial）**，东亚分区 50%12+1=**3（民国书衣 Republic-Era Book Jacket）**。
> 外观家族只用来横比，不设禁令；三版色彩都接受「墨绿×暖白」品牌约束，差异落在骨架与气质。

## A1 · 深绿书斋 Forest Study ｜最佳设计师
- **逻辑与来源**：原研哉（Kenya Hara，「白」与「素材即主角」）的留白语法 × Massimo Vignelli 的严格网格；把抽屉的深墨绿身份头**升级为整条左侧导航**。
- **借的是什么**：全高深墨绿导航（≈240px）+ 暖象牙画布（#F4F1EA）+ 纯白浮起卡面；页面标题用 Noto Serif SC 衬线大字；表格用「发丝横线账册」而非竖边框；绿色只做激活与主按钮；数字用等宽。
- **主角素材**：真实的成员行与头像字母；靠排印节奏而非装饰。
- **骨架**：固定深绿左栏 + 暖象牙主区；头部「眉标 + 衬线大标题 + 副标题」；搜索与指标一行；账册式表格。
- **胆量花在哪**：整条深绿导航压在暖象牙画布上，一个动作定气质。
- **form 来自内容的哪里**：这是云笔记产品，管理端也该有「书房/帐房」的安静·可读，长时间看不累。

## A2 · 暖纸账房 Warm Ledger ｜最佳设计师
- **逻辑与来源**：吕敬人书籍设计（版心呼吸、旁注栏、朱印一点）× 传统账册排印。
- **借的是什么**：全暖纸底（#F3EEE2）浅色、无深色面；朱红只用于一枚小印与极少数强调；标题旁一个竖排小注栏；表格是双线细框账册；激活态用苔绿细线而非色块。
- **主角素材**：纸面质感 + 账册格线 + 朱印小标。
- **骨架**：浅色左栏 + 暖纸主区 + 右侧窄旁注列；标题「版心偏上」；账册表。
- **胆量花在哪**：把管理端做成一本「账簿」，朱印与竖排注在效率界面里极少见。
- **form 来自内容的哪里**：云笔记=文字与纸的生意，账房纸感直接呼应产品本身。

## B1 · 薄荷工作台 Mint Workspace ｜现实参照
- **逻辑与来源**：Linear / Notion 的浅色精密 SaaS 后台（同媒介真实参照）。
- **借的是什么**：白/极浅灰底 + 薄荷墨绿单点；白色细边卡片；4 个扁平指标卡；密度适中的数据表 + pill 状态标签；键盘式全局搜索；小号等宽类目标签。
- **主角素材**：数据密度本身；克制的排印与对齐。
- **骨架**：浅色左栏 + 顶部条 + 卡片化指标 + 工具栏 + 密集表 + 分页。
- **胆量花在哪**：几乎不装饰，靠密度、对齐、微交互取胜。
- **form 来自内容的哪里**：后台是高频数据操作，清爽高效就是它该有的样子。

## B2 · 晨雾控制台 Mist Console ｜现实参照
- **逻辑与来源**：Vercel / Resend 仪表盘（同媒介真实参照）的发丝线控制台语言。
- **借的是什么**：冷白底 + 单一墨绿 + 1px 发丝线分区、锐利小圆角；左侧**二级筛选轨**（部门/状态/角色竖排）；等宽大写小标签；表格无斑马、只发丝线。
- **主角素材**：发丝线与等宽标签的系统感。
- **骨架**：主左栏 + 内容区再分「筛选轨 + 表」两栏；页头一行 + 工具行。
- **胆量花在哪**：多一层筛选轨，把「查找」前置成结构。
- **form 来自内容的哪里**：成员管理常按部门/角色筛，竖排筛选轨比弹层更贴合反复筛选的动作。

## C1 · 墨绿画屏 Grove Dark ｜秒数轮盘
- **逻辑与来源**：网页 #11「暗色双色侧栏开发者作品集 Dark Editorial」（Brittany Chiang）— 深底 + 单一荧光 accent + 等宽编号。
- **借的是什么**：深墨绿近黑外壳（#0E1A15 / #0B120F）+ **暖白卡面浮起**；单一荧光青绿 accent（#6FE3B0）；等宽编号 section（01/02）；左栏导航 + 右侧工作区。
- **主角素材**：暗场里浮起的暖白内容卡，高对比但不刺眼。
- **骨架**：深色左栏 + 深色画布 + 中央暖白工作卡；表格等于卡片内浅色区。
- **胆量花在哪**：整屏深色外壳 + 暖白卡，一个「画屏/暗房」姿态。
- **form 来自内容的哪里**：笔记与写作常在夜里发生，深色工作台是创作者真实的第二环境。

## C2 · 竹影双栏 Bamboo Split ｜秒数轮盘
- **逻辑与来源**：东亚 #3「民国书衣 Republic-Era Book Jacket」— 低饱和土黄/灰绿纸色 + 墨黑 + 一点朱红 + 竖排题签 + 双线框 + 平涂几何。
- **借的是什么**：暖纸 + 墨 + 朱红三色；左侧**竖排长题签**与双线外框；右上角平涂几何水纹/山形；右区表格用细线格；激活用朱红细线。
- **主角素材**：竖排题签 + 朱印 + 几何平涂纹样。
- **骨架**：左侧竖排题签轨（窄）+ 右侧横向内容；外框双线；表在右。
- **胆量花在哪**：把中文竖排题签做成导航结构，一眼是「中国的、书的」。
- **form 来自内容的哪里**：笔记产品的文化根在纸与书，民国书衣把这点讲得最直白。
