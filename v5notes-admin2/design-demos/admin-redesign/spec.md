# V5Notes2 管理端 · 整体风格与主题重设计 — 设计 Spec

## 项目
v5notes-admin2（V5Notes2 云笔记 · 管理控制台），Vue 3 + Element Plus 的后台管理系统。
本次不是改单个弹窗，而是**全局视觉语言与主题**（侧栏 / 顶栏 / 面包屑 / 页面标题 / 筛选区 / 数据表 / 分页 / 状态与控制 / 卡片 / 浅色+暗色令牌）的重设计。

## 参照物（用户指定）
用户已批准「用户新增/编辑侧滑抽屉」方向 C（见 design-demos/user-dialog/dir-3.png，用户原话「确认走 C」）。
参照 = 该抽屉的视觉 DNA：**深墨绿身份头（#0f3d33→#1c5a48）+ 暖白卡面（#fff）+ 微暖纸感内容区（#fbfcfb）+ 细边框（#e8ecea）+ 低饱和墨绿/暖灰文案 + MiSans 字体 + 10–14px 圆角 + 克制的阴影**。
任务：把这一套「墨绿 × 暖白」的语言，从抽屉扩展到整个后台外壳与所有页面组件，形成统一主题（含浅色与暗色两态）。

## 受众与场景
工作空间管理员 / 运营，长时间在桌面（1440–1920 宽）浏览与维护成员、角色、部门、客户端账号、文件与系统监控。高频读写表格、频繁打开表单抽屉。

## 核心信息（每屏都要在第一眼交代）
当前所在位置、本页要处理的对象与数量、可执行的主要动作、以及列表的可读层级（成员 = 人 + 账号 + 部门 + 角色 + 状态 + 活跃 + 操作）。

## 情感基调
克制、可靠、清楚；安静的东方纸感与绿色让「云笔记」这层产品温度透出来，但不牺牲后台的效率与密度。

## 输出格式（三版必须统一，否则无法横比）
- 单个独立 HTML，桌面画布固定 **1440 × 1024**（含右侧已打开的编辑抽屉，抽屉宽 610px，与已批准抽屉一致）。
- 内容完全一致（同一套菜单、同一页、同一批成员数据、同一个抽屉表单内容），只换设计。
- 每版一张 1440×1024 截图 PNG。缩略图为 6 格 480×300 总览。

## 已知约束
- 品牌色：沿用已批准的墨绿系；三方向可在「墨绿×暖白」语境里各自诠释（某版可加第二强调色，如朱红/青绿），但差异必须落在**骨架与气质**，不是只换配色。
- 字体：中文 MiSans / HarmonyOS Sans SC / PingFang SC；可用 Noto Serif SC 做衬线标题（本地无 MiSans 时用系统栈兜底，截图环境用 PingFang SC）。
- Element Plus 语义色（primary/success/warning/danger）需映射到新主色。
- 可读性硬底线：正文 ≥14px、标签 ≥12px、正文对比度 ≥4.5:1。
